# Meta-Prompts — AI Agent Cybersecurity Skills Pack v1.0

7 個 Meta-Prompt：讓 AI 幫你生成更多安全檢查 Prompt 和技能

---

## M01 — 為任意技術棧生成安全 Checklist
```
你是資深 DevSecOps 工程師。請為以下技術棧生成完整的安全開發 Checklist：
技術棧：[前端框架/後端框架/資料庫/雲端平台]

依開發階段組織：
1. 設計階段（威脅建模、安全需求）
2. 開發階段（安全編碼規範、SAST）
3. 測試階段（安全測試、DAST、滲透測試）
4. 部署階段（配置審查、IaC 安全）
5. 運維階段（日誌監控、事件回應）

每個項目：具體可執行的動作 + 工具推薦 + 優先等級
```

## M02 — 從 CVE 生成修復 Prompt
```
你是資安專家。我的系統使用 [套件名稱@版本]，該版本存在 [CVE-XXXX-XXXXX]。

請：
1. 用白話解釋這個漏洞的攻擊原理
2. 評估我們的使用情境是否真的受影響（影響範圍評估）
3. 生成具體的 Prompt，讓 Claude Code 幫我找出所有受影響的程式碼位置
4. 提供修復方案（升級版本 + 暫時緩解措施）
5. 生成驗證修復有效的測試案例
```

## M03 — 為任意端點生成安全測試 Prompt
```
你是滲透測試師。請為以下 API 端點生成全面的安全測試 Prompt 套件：
端點：[HTTP Method] [URL] [請求體]

生成涵蓋：
1. 認證繞過測試 Prompt
2. 輸入驗證測試 Prompt（injection payloads）
3. 授權測試 Prompt（IDOR / 權限提升）
4. 業務邏輯測試 Prompt（邊界值、競態條件）
5. 資訊洩漏測試 Prompt（錯誤訊息、Header）

每個 Prompt 都應可直接貼入 Claude Code 執行
```

## M04 — 從架構圖生成威脅模型
```
你是架構安全評審師。根據以下系統架構描述，生成完整威脅模型：
架構描述：[貼上架構]

輸出：
1. 按 STRIDE 分類的威脅清單（每個威脅附攻擊情境描述）
2. 信任邊界圖（文字版 DFD）
3. 按 DREAD 評分的前 10 大威脅
4. 對應的 MITRE ATT&CK Technique ID
5. 針對每個 High 威脅的緩解措施 Prompt（可直接執行）
```

## M05 — 生成合規文件草稿
```
你是合規顧問。根據以下系統描述，生成 [GDPR / SOC 2 / ISO 27001] 合規文件草稿：
系統描述：[貼上描述]

生成：
1. 資料處理活動記錄（ROPA / Record of Processing Activities）
2. 資料流程圖（哪些個資被收集、如何使用、何時刪除）
3. 技術與組織措施說明（TOMs）
4. 現有控制措施清單
5. 合規缺口識別 + 優先修復建議
```

## M06 — 生成安全培訓材料
```
你是安全培訓師。請為 [開發團隊 / 後端工程師 / 前端工程師 / DevOps] 生成 30 分鐘的互動安全培訓材料：

包含：
1. 最相關的 3 個安全威脅（含真實案例）
2. 5 個「這段程式碼哪裡不安全？」練習題（含解答）
3. 安全開發好習慣清單（可貼在桌上的版本）
4. 快速參考資源（工具、文件連結）
5. 30 天後的知識驗收測驗（5 題選擇題）
```

## M07 — 自動生成新安全技能
```
你是 AI Agent 技能設計師。請根據以下新漏洞或技術，生成一個符合本 Skills Pack 格式的新技能文件：

漏洞/技術：[描述]

技能文件格式：
- 分類與框架
- 用途（2-3 行說明）
- 使用方式（結構化 Prompt 模板）
- 修復/配置範例（程式碼）
- 參考框架（官方文件 + CVE/CWE）

確保技能可直接整合到 Claude Code SKILLS.md
```
