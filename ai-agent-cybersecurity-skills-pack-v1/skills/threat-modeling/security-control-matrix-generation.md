# 安全控制矩陣生成

**分類：** 威脅建模 | **框架：** CIS Controls v8  
**適用平台：** Claude Code、Cursor、Copilot

## 用途
根據組織規模與技術棧自動生成優先實施的安全控制矩陣，適合新創或中小企業快速建立安全基線。

## 使用方式
```
請根據以下環境生成安全控制實施矩陣：
- 組織規模：[人數]
- 技術棧：[前端/後端/雲端/資料庫]
- 現有安全工具：[已使用的工具]
- 合規目標：[SOC2 / ISO27001 / 無特定要求]

依 CIS Controls v8 IG1/IG2/IG3 分層輸出：
1. 立即實施（IG1，基本衛生）
2. 三個月內（IG2，中等成熟度）
3. 六個月內（IG3，高成熟度）

每項控制附：工具建議 + 實施難度 + 預估時間
```

## 參考框架
- CIS Controls v8（18 個控制項）
