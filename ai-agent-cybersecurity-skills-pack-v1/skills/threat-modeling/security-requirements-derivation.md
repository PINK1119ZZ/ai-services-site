# 安全需求推導

**分類：** 威脅建模 | **框架：** NIST CSF 2.0  
**適用平台：** Claude Code、Cursor、Copilot

## 用途
從業務需求自動推導對應的安全需求，確保安全考量在開發初期就被納入（Shift Left Security）。

## 使用方式
```
請根據以下業務需求推導對應的安全需求：

業務需求：[描述功能/業務邏輯]

輸出：
1. 機密性需求（Confidentiality）
2. 完整性需求（Integrity）
3. 可用性需求（Availability）
4. 不可否認性需求（Non-repudiation）
5. 對應的技術控制措施建議
6. 驗收標準（Acceptance Criteria）
```

## 參考框架
- NIST CSF 2.0 Protect Function
- ISO 27001 Annex A Controls
- OWASP ASVS（Application Security Verification Standard）
