# 威脅情境建模

**分類：** 威脅建模 | **框架：** MITRE ATT&CK  
**適用平台：** Claude Code、Cursor、Copilot

## 用途
針對特定功能或系統，建構真實攻擊者視角的威脅情境，幫助開發者理解「攻擊者實際上會怎麼做」。

## 使用方式
```
請為 [功能/系統] 建構威脅情境模型，攻擊者畫像為 [外部駭客/惡意內部人員/自動化掃描器]：
1. 攻擊動機與目標
2. 可能的攻擊路徑（步驟式）
3. 每步驟對應的 MITRE ATT&CK Technique ID
4. 現有防禦措施的有效性評估
5. 建議補強的防禦控制
```

## 輸出範例
```
攻擊路徑：
T1190 → T1078 → T1003 → T1486
（利用公開漏洞 → 竊取憑證 → 傾卸憑證 → 勒索軟體部署）
```
