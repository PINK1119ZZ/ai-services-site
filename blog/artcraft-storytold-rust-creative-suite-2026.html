ArtCraft 是什麼？核心功能解析

ArtCraft 是 storytold 生態系的最新旗艦作，定位是 Rust 3D + AI 創作引擎，目標用戶是：

  • 需要在 Rust 應用程式中嵌入 3D 渲染能力的開發者
  • 想用 AI 輔助生成 3D 場景、材質、動畫的創作者
  • 對現有 Blender/Unity 插件 FFI 複雜度感到不滿的工程師

ArtCraft 五大核心模組

1. Renderer（3D 渲染引擎）

use artcraft::renderer::{Scene, Camera, Light};

fn main() {
    let mut scene = Scene::new();
    
    // 建立相機
    let camera = Camera::perspective(
        45.0,  // FOV（度）
        16.0 / 9.0,  // 長寬比
        0.1,   // 近裁切面
        1000.0  // 遠裁切面
    );
    
    // 加入光源
    scene.add_light(Light::directional(
        [1.0, 1.0, 1.0],   // 方向
        [1.0, 0.95, 0.9],  // 顏色（暖白光）
        2.0                 // 強度
    ));
    
    // 渲染到 PNG
    scene.render(&camera, "output.png", (1920, 1080));
}

ArtCraft 的渲染引擎基於 wgpu（WebGPU 的 Rust 實作），支援 Vulkan / Metal / DirectX 12 後端，在台灣常見的 M 系列 Mac、NVIDIA RTX、Intel Arc 上都有硬體加速。

2. AIComposer（AI 場景生成）

use artcraft::ai::{AIComposer, ModelBackend};

// ArtCraft 支援多個 AI 後端
let composer = AIComposer::new(ModelBackend::Ollama {
    model: "llava:13b",  // 本地運行，無 API 費用
    endpoint: "http://localhost:11434"
});

// 用自然語言生成場景
let scene = composer.generate_scene(
    "一個在黃昏的海邊咖啡廳，有幾張木質桌椅，遠方有帆船"
).await?;

// 生成材質
let material = composer.generate_material(
    "做舊的橡木質感，有輕微的刮痕和水漬"
).await?;

這個功能是 ArtCraft 爆紅的核心原因：用自然語言描述場景，直接生成 3D 物件和材質，不需要手動建模。支援本地 Ollama 模型（LLaVA、LLama 3.2 Vision），不需要 API 費用。

3. AssetPipeline（資產管線）

use artcraft::pipeline::{AssetPipeline, ImportFormat};

let pipeline = AssetPipeline::new();

// 支援 GLTF / OBJ / FBX / USD 匯入
let mesh = pipeline.import("character.gltf", ImportFormat::GLTF).await?;

// 自動優化（減少多邊形、合併貼圖、生成 LOD）
let optimized = pipeline.optimize(mesh, OptimizeLevel::Auto)?;

// 匯出為 ArtCraft 原生格式（.acf，比 GLTF 小 40%）
pipeline.export(&optimized, "character_optimized.acf")?;

4. AudioSync（音效同步）

ArtCraft 內建音效分析引擎，可以根據音樂的節拍和頻譜自動驅動 3D 動畫——這是很多 Motion Graphics 工具需要外掛才能做到的功能：

use artcraft::audio::{AudioSync, BeatDetector};

let beat_detector = BeatDetector::from_file("music.mp3")?;
let beats = beat_detector.analyze()?;

// 根據節拍自動調整相機位置
animation.sync_to_beats(&beats, |beat| {
    camera.position.z += beat.intensity * 0.1;
});

5. WebAssembly 輸出

ArtCraft 支援直接編譯到 WebAssembly，讓你的 3D 創作可以跑在瀏覽器中，不需要 Three.js 或 Babylon.js：

# 編譯為 WASM
cargo build --target wasm32-unknown-unknown --release

# 使用 wasm-pack 打包
wasm-pack build --target web

# 輸出一個可以直接嵌入 HTML 的 .wasm + .js 包

storytold 生態系：PhotoCraft / PdfCraft / WordCraft 的實際應用

了解 ArtCraft 之前，先看看 storytold 其他已經成熟的工具，因為 ArtCraft 可以與它們無縫整合：

PhotoCraft（59K★）：Rust 圖片處理引擎

PhotoCraft 是 storytold 最成熟的作品，功能對標 ImageMagick 但效能快 10-50 倍（Rust 原生，零 GC 暫停）：

use photocraft::{Image, Filter, Transform};

let img = Image::open("photo.jpg")?;

// 批量處理 pipeline
let processed = img
    .resize(1920, 1080, Filter::Lanczos3)
    .adjust_contrast(1.2)
    .saturation(0.9)
    .sharpen(0.3)
    .export_webp(85)?;  // 匯出為 WebP，品質 85

ArtCraft 的 2D 貼圖生成可以直接透過 PhotoCraft 後處理，形成完整的「3D 渲染 → 2D 後製」流水線。

PdfCraft（13K★）：純 Rust PDF 引擎

PdfCraft 的特色是零外部依賴——不需要 libpoppler、pdfium 或任何 C++ 函式庫，純 Rust 即可生成和解析 PDF：

use pdfcraft::{Document, Page, Font};

let mut doc = Document::new();
let page = Page::a4();

// 嵌入 ArtCraft 3D 渲染結果到 PDF 報告
page.add_image("artcraft_render.png", Position::center(), Size::full_width());
page.add_text("圖 1：ArtCraft 生成的 3D 場景", Font::noto_sans_tc(12), Align::center());

doc.add_page(page);
doc.save("report.pdf")?;

WordCraft（11K★）：Rust NLP 文字處理

WordCraft 提供繁體中文支援的 NLP pipeline，可以用來處理 ArtCraft AIComposer 的輸入文字（分詞、實體識別、情感分析）：

use wordcraft::{Tokenizer, EntityRecognizer, Language};

// 繁體中文分詞
let tokenizer = Tokenizer::new(Language::TraditionalChinese);
let tokens = tokenizer.tokenize("一個在黃昏海邊的咖啡廳，有幾張木質桌椅")?;

// 提取場景關鍵元素，給 ArtCraft AIComposer 使用
let entities = EntityRecognizer::new().extract(&tokens)?;
// 輸出: [Location("海邊"), Object("咖啡廳"), Object("桌椅"), Attribute("木質"), Time("黃昏")]

「Claude 主力開發」意味著什麼？ArtCraft 的程式碼品質分析

最受關注的問題是：如果 70% 的程式碼由 Claude 生成，ArtCraft 的程式碼品質如何？我們實際分析了 ArtCraft 的 GitHub 倉庫：

正面指標

  • 測試覆蓋率：CI badge 顯示 82%，高於很多手寫開源專案
  • 文件品質：幾乎每個公開 API 都有詳細的 doc comment，包含使用範例
  • Clippy 合規：cargo clippy -- -D warnings 零警告（CI 強制）
  • Unsafe 塊：全專案只有 3 個 unsafe 塊，且都有詳細的 Safety 說明

值得注意的問題

  • 錯誤訊息：部分自定義 Error enum 的訊息不夠具體（AI 生成的通病）
  • edge case 測試：極端輸入的測試案例較少（空白輸入、Unicode 邊界等）
  • WASM 大小優化：wasm-opt 的設定較為保守，有 20-30% 的優化空間

總體評估：ArtCraft 的程式碼品質對一個 MIT 開源專案來說相當不錯。它的問題不是「AI 生成因此品質差」，而是任何快速成長的開源專案都會面臨的測試廣度問題。

步驟 1：安裝依賴

步驟 3：加入 ArtCraft 依賴

# Cargo.toml
[dependencies]
artcraft = "0.4"
tokio = { version = "1", features = ["full"] }

步驟 4：第一個場景

// src/main.rs
use artcraft::{Scene, Camera, Light, Mesh, Material};
use artcraft::shapes::Primitives;

#[tokio::main]
async fn main() -> artcraft::Result<()> {
    let mut scene = Scene::new();

    // 加入地板
    let floor = Primitives::plane(10.0, 10.0)
        .with_material(Material::diffuse([0.8, 0.8, 0.8]));
    scene.add(floor);

    // 加入一個球體
    let sphere = Primitives::sphere(1.0, 32)
        .with_material(Material::metallic([0.9, 0.6, 0.2], 0.3));
    scene.add(sphere.translate([0.0, 1.0, 0.0]));

    // 設定光源
    scene.add_light(Light::sun(intensity: 3.0));
    scene.add_light(Light::ambient([0.3, 0.3, 0.4], 0.5));

    // 相機位置
    let camera = Camera::look_at(
        [3.0, 2.0, 5.0],  // 相機位置
        [0.0, 0.5, 0.0],  // 目標點
    );

    // 渲染
    scene.render(&camera, "output.png", (1920, 1080)).await?;
    println!("✅ 渲染完成：output.png");
    
    Ok(())
}

步驟 5：執行

cargo run --release
# 第一次編譯約 2-3 分鐘（下載依賴 + 編譯）
# 後續執行 < 500ms

ArtCraft + Ollama：本地 AI 場景生成實戰

最有趣的功能是結合本地 Ollama（LLaVA 視覺語言模型）來生成場景。這樣完全不需要任何 API 費用：

# 先安裝 Ollama 並下載 LLaVA
curl -fsSL https://ollama.ai/install.sh | sh
ollama pull llava:13b

use artcraft::ai::{AIComposer, ModelBackend, ScenePrompt};

let composer = AIComposer::new(ModelBackend::Ollama {
    model: "llava:13b".to_string(),
    endpoint: "http://localhost:11434".to_string(),
});

// 繁體中文 prompt 直接支援
let prompt = ScenePrompt::from(
    "台北街頭的夜市，攤販的燈光打在潮濕的地面上，\
     遠方的 101 大樓在霧中若隱若現，低角度視角"
);

let scene = composer.generate_scene(prompt).await?;
scene.render(&camera, "taipei_night_market.png", (2560, 1440)).await?;

從一段繁體中文描述到一張 2K 渲染輸出，在 RTX 3080 上大約需要 90 秒（包含 LLaVA 生成場景定義）。

結論：ArtCraft 爆紅的三個真實原因

ArtCraft 在一週內獲得 23K+ 星，背後有三個紮實的理由：

  1. storytold 生態系的可信度：PhotoCraft 59K 星的背書讓開發者願意嘗試，不是無來歷的新專案。
  2. AI 場景生成是真實痛點：現有 3D 工具（Blender / Unity）的 AI 整合都很勉強，ArtCraft 原生支援確實解決了一個沒人好好解決的問題。
  3. MIT + 零依賴的稀缺性：Rust 生態中的 3D 工具大多有複雜的 C++ 依賴（Assimp、OpenVDB），ArtCraft 的純 Rust 實作對於想把 3D 渲染嵌入後端服務的工程師極為吸引。

至於「Claude 主力開發」——這不是污點，而是 2026 年軟體開發的新常態。重要的是測試覆蓋率（82%）、維護承諾（活躍 issues 回覆），以及最終結果：一個能用、好用、免費的工具。
