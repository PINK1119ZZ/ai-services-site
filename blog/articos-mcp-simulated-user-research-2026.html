Articos MCP 是什麼？為什麼 30 分鐘能完成使用者研究？

Articos MCP 是一個基於 MCP（Model Context Protocol）的 AI 使用者研究工具，能在 30 分鐘內完成傳統需要 4-8 週的使用者研究流程。核心技術是「模擬買家（Simulated Personas）」——基於你的 ICP（Ideal Customer Profile，理想客戶畫像）建立 9 種不同的 AI persona，直接在 Claude / ChatGPT 中執行研究任務。

核心數據（Articos 官方）

  • 86% 與人類研究一致性（vs Baymard Institute / Nielsen Norman Group 真實研究結果）
  • 30 分鐘完成完整研究（vs 傳統 4-8 週 + $5,000-20,000）
  • 9 種 persona 同時執行（每個 persona 獨立推理，避免 echo chamber）
  • MCP server 架構（無需切換工具，直接在 Claude Desktop / ChatGPT 內使用）

為什麼這麼快？

傳統使用者研究流程：

  1. 招募受試者（1-2 週）
  2. 排程訪談（1-2 週）
  3. 執行訪談（1-2 週，每人 1 小時）
  4. 分析整理（1-2 週）

總時間：4-8 週，費用 $5,000-20,000

Articos MCP 流程：

  1. 輸入 ICP（5 分鐘）
  2. AI 建立 9 個 persona（5 分鐘）
  3. 同步執行研究任務（15 分鐘）
  4. 生成報告（5 分鐘）

總時間：30 分鐘，費用 $0-99/月（取決於方案）

技術解析：Articos MCP 如何模擬買家？

MCP（Model Context Protocol）是什麼？

MCP 是 Anthropic 在 2026 年 6 月發布的開放協定，讓 AI 模型能直接呼叫外部工具與資料源。Articos MCP 是一個MCP server，提供以下功能給 Claude / ChatGPT：

  • articos.create_persona(icp)：基於 ICP 建立 persona
  • articos.run_study(task, personas)：執行研究任務
  • articos.generate_report(results)：生成報告

9 種 Persona 如何建立？

Articos 根據你的 ICP（例如「台灣 SaaS 創業者，30-45 歲，年營收 $100K-500K」）建立 9 種不同的 persona：

Persona 類型 特徵 決策模式
Innovator（創新者） 早期採用者，願意冒險 功能優先，價格次要
Budget-Conscious（預算派） 價格敏感，追求 CP 值 價格優先，功能次要
Security-First（安全派） 重視隱私與合規 安全優先，其他次要
Efficiency-Driven（效率派） 追求省時間，願意付費 自動化優先，整合性次要
Skeptic（懷疑派） 對 AI 有疑慮，需要證據 案例優先，承諾次要
Community-Oriented（社群派） 重視社群支援與教學 文件優先，功能次要
Technical Expert（技術派） 需要 API / SDK / 自架 可擴展性優先，UI 次要
Non-Technical（非技術派） 需要簡單易用的 UI 易用性優先，功能次要
Scale-Focused（規模派） 企業客戶，需要規模化方案 穩定性優先，價格次要

86% 準確度如何驗證？

Articos 使用以下方式驗證準確度：

  1. 對照組：取得 Baymard Institute 與 Nielsen Norman Group 的真實研究報告（200+ 項研究）
  2. 相同任務：讓 Articos 模擬 persona 執行相同研究任務（例如「測試 SaaS 定價頁易用性」）
  3. 結果對比：比較 Articos 與真實研究的關鍵發現（例如「定價不透明」「CTA 位置不明顯」）
  4. 一致性：86% 的關鍵發現一致（vs 人類研究員之間的一致性約 91%）

真實案例：用 Articos MCP 測試 SaaS Landing Page

背景

假設你正在開發一個「AI Email 自動化工具」，定價 $49/月，目標客戶是「台灣中小企業行銷人員」。你想知道：

  • Landing page 的 CTA 是否清楚？
  • 定價是否合理？
  • 哪些功能最吸引人？

Step 1：輸入 ICP（5 分鐘）

在 Claude Desktop / ChatGPT 中，執行 Articos MCP：

@articos 請幫我建立 persona，ICP 如下：
- 職位：台灣中小企業行銷人員
- 年齡：28-40 歲
- 公司規模：10-50 人
- 痛點：Email 手動發送太花時間，需要自動化
- 預算：$50-150/月
- 技術能力：中等（會用 Mailchimp / HubSpot）

Step 2：AI 建立 9 個 Persona（5 分鐘）

Articos 自動建立 9 個 persona，例如：

  • Persona 1（Budget-Conscious）：「我是小公司行銷，預算只有 $50/月，需要基本自動化就好」
  • Persona 2（Efficiency-Driven）：「我願意付 $150/月，但要能省我每週 10 小時」
  • Persona 3（Security-First）：「我們公司需要符合 GDPR，你們有通過哪些認證？」

Step 3：執行研究任務（15 分鐘）

輸入研究任務：

@articos 請讓這 9 個 persona 測試我的 landing page：
https://myproduct.com/landing

請回答：
1. CTA 是否清楚？
2. 定價是否合理？
3. 哪些功能最吸引人？
4. 有什麼疑慮或不清楚的地方？

Step 4：生成報告（5 分鐘）

Articos 生成完整報告，包含：

關鍵發現

  • ✅ CTA 清楚（9/9 persona 認為「開始免費試用」按鈕明顯）
  • ⚠️ 定價有疑慮（6/9 persona 認為 $49/月偏高，建議 $29-39/月）
  • ✅ 最吸引功能：「自動 follow-up」（8/9 persona 提及）
  • ❌ 最大疑慮：「沒有提到 GDPR 合規」（3/9 persona 提及，Security-First 類型）

建議改進

  1. 調整定價至 $29-39/月（或新增基礎方案）
  2. 在 landing page 顯著位置加入「GDPR 認證」badge
  3. 強調「自動 follow-up」功能（目前在第三段，建議移至第一段）

如何在 Claude / ChatGPT 中使用 Articos MCP？

前置需求

  • Claude Desktop：1.40.0 以上版本（支援 MCP）
  • 或 ChatGPT：需開啟 Advanced Data Analysis（付費版功能）
  • Articos 帳號：至少 Free 方案

安裝步驟（Claude Desktop）

Step 1：安裝 Articos MCP Server

npm install -g @articos/mcp-server

Step 2：設定 Claude Desktop

編輯 ~/.claude/config.json：

{
  "mcpServers": {
    "articos": {
      "command": "articos-mcp",
      "args": ["--api-key", "YOUR_ARTICOS_API_KEY"]
    }
  }
}

Step 3：重啟 Claude Desktop

重啟後，在對話框中輸入 @articos 即可看到可用指令。

使用範例

@articos create_persona
ICP: SaaS founders, 30-45, $100K-500K ARR, need user research automation

@articos run_study
Task: Test landing page https://example.com
Focus: pricing clarity, CTA effectiveness, value proposition

@articos generate_report
Format: executive summary + detailed insights

限制與注意事項

Articos MCP 不能取代的情境

  1. 深度訪談：需要探索「為什麼」的情境，AI persona 無法提供真實情感脈絡
  2. 實體產品測試：需要觸摸、嗅覺等感官體驗
  3. 極小眾市場：AI 訓練資料可能不足以模擬特定小眾（例如「台灣有機農場主」）
  4. 合規需求：某些產業（醫療、金融）需要真實使用者研究記錄

最佳使用時機

  • ✅ 快速驗證：產品早期，需要快速測試多個方向
  • ✅ 迭代優化：每週 / 每月定期測試，持續改進
  • ✅ 多變數測試：同時測試 3-5 種方案，選出最佳
  • ✅ 補充傳統研究：在真實研究前，先用 Articos 排除明顯問題
