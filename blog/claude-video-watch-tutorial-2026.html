想讓 Claude AI 分析 YouTube 影片、提取關鍵字幕、生成內容摘要嗎？Claude Video 是一個開源 MCP Server，讓 Claude Desktop 能「看懂」影片內容，5 分鐘即可上手。本文提供完整教學，從安裝、設定到實際應用，幫助影片創作者、研究者快速掌握這項工具。

什麼是 Claude Video？

Claude Video 是一個 MCP (Model Context Protocol) Server，由開源社群開發，讓 Claude AI 能夠分析影片內容。它整合了 Whisper API（語音轉文字）與 YouTube 字幕提取功能，讓 Claude Desktop 使用者能直接在對話中分析影片，無需手動下載或轉錄。

核心功能

  • YouTube 影片分析：輸入 YouTube 連結，Claude 自動提取字幕或音訊，生成內容摘要
  • 本地影片支援：上傳 MP4、MOV 等格式，Claude 轉錄音訊並分析內容
  • 多語言字幕：支援英文、中文、日文等 90+ 種語言，自動辨識
  • 時間戳標記：生成帶時間碼的字幕，方便定位關鍵段落

💡 適用場景

  • YouTube 創作者：分析競品影片策略、提取關鍵字、研究觀眾喜好
  • 研究者：快速提取演講、訪談重點，生成文獻筆記
  • 內容團隊：將影片轉為部落格文章、社群貼文、腳本大綱
  • 學習者：總結線上課程、會議錄影，建立個人知識庫

安裝 Claude Video：3 步驟快速設定

步驟 1：安裝 Node.js 與 npx

Claude Video 需要 Node.js 18 以上版本。打開終端機，執行以下指令檢查：

node -v
# 應顯示 v18.0.0 或更高版本

若未安裝，前往 nodejs.org 下載最新版本。

步驟 2：取得 Groq API Key（免費）

Claude Video 使用 Groq 的 Whisper API 進行語音轉文字（速度比 OpenAI 快 10 倍）。前往 Groq Console 註冊並取得 API Key：

  1. 訪問 console.groq.com（免費註冊）
  2. 點選 "API Keys" → "Create API Key"
  3. 複製生成的 Key（格式：gsk_...）

💰 費用說明：Groq 提供每月 14,400 分鐘免費 Whisper API 額度，約可轉錄 240 小時影片，個人使用綽綽有餘。

步驟 3：設定 Claude Desktop

打開 Claude Desktop 設定檔（位置依作業系統不同）：

  • macOS：~/Library/Application Support/Claude/claude_desktop_config.json
  • Windows：%APPDATA%\Claude\claude_desktop_config.json

加入以下設定（記得替換 YOUR_GROQ_API_KEY）：

{
  "mcpServers": {
    "claude-video": {
      "command": "npx",
      "args": [
        "-y",
        "@bradautomates/claude-video"
      ],
      "env": {
        "GROQ_API_KEY": "YOUR_GROQ_API_KEY"
      }
    }
  }
}

儲存檔案後，重新啟動 Claude Desktop。若設定成功，介面右下角會出現 🔌 圖示，顯示 "claude-video" 已連線。

常見問題排解

問題 1：Claude Desktop 沒有顯示 🔌 圖示

解決方法：

  • 檢查設定檔 JSON 格式是否正確（建議用 JSONLint 驗證）
  • 確認 GROQ_API_KEY 沒有多餘空格或引號錯誤
  • 完全關閉 Claude Desktop（Mac 用戶需從 Dock 右鍵退出），重新開啟

問題 2：YouTube 影片提取失敗

可能原因：

  • 影片未開啟字幕功能（需創作者手動啟用）
  • 影片為會員專屬或私人影片
  • 影片音訊過長（超過 Groq 免費額度限制）

解決方法：改為上傳本地影片檔案（從 YouTube 下載 MP4），或使用付費 Groq 方案。

問題 3：轉錄結果有錯字或語句不通順

解決方法：

  • 確保影片音質清晰（背景噪音會影響準確率）
  • 對於專業術語密集的影片，可在提示詞中先提供術語清單：「這支影片討論機器學習，常見術語包括：transformer、attention mechanism、fine-tuning」

Claude API 直接呼叫（進階）

如果你想完全客製化影片分析邏輯，可以直接使用 Claude API + Whisper API：

// 範例：Node.js 整合
const Anthropic = require('@anthropic-ai/sdk');
const anthropic = new Anthropic({ apiKey: process.env.CLAUDE_API_KEY });

async function analyzeVideo(videoUrl) {
  const message = await anthropic.messages.create({
    model: 'claude-sonnet-4-20250514',
    max_tokens: 4096,
    messages: [{
      role: 'user',
      content: `請分析這支影片並生成摘要：${videoUrl}`
    }]
  });
  return message.content;
}

結論：如果你已是 Claude Desktop 用戶，Claude Video 幾乎零成本，且 AI 分析能力遠超其他工具。唯一需要的投資是 Claude Pro（選配），但對重度使用者來說絕對值得。

資料安全與隱私保護

使用影片分析工具時，資料安全是重要考量：

Claude Video 如何處理你的資料？

  • 本地處理：影片檔案不會上傳至第三方伺服器（除非透過 YouTube 連結）
  • API 加密：與 Claude API 和 Groq API 的通訊皆使用 HTTPS 加密
  • 無資料留存：Anthropic 不會儲存你的對話內容用於訓練（需啟用「不用於訓練」選項）

企業級隱私保護建議

如果你處理的是機密會議或內部培訓影片：

  1. 自架 MCP Server：將 Claude Video 部署在自己的伺服器（DigitalOcean 或 AWS）
  2. 使用 VPN：確保所有 API 請求透過企業 VPN 傳輸
  3. 定期刪除：從 Claude Projects 手動刪除敏感對話記錄

🔒 企業資安建議

如果您的公司有嚴格資安政策，可以選擇使用 Claude Enterprise Plan，提供：

  • SSO（Single Sign-On）整合
  • 資料駐留保證（不離開特定地區）
  • 完整稽核日誌（Audit logs）
  • 優先技術支援
