Coldtea.ai 是什麼？一句話講清楚

Coldtea.ai 是一套 AI 驅動的 E2E 測試 + Production 監控平台，整合三個核心功能：

  • 自然語言測試生成：你用中文或英文描述要測什麼（例如「註冊流程跑完不會噴錯」），Coldtea 自動生成瀏覽器測試腳本、執行、回報結果。
  • AI coding agent 整合：測試失敗時，Coldtea 會自動叫 Claude Code / Codex / OpenCode 去讀 log、定位問題、建議修復，甚至直接開 PR。
  • Production 監控：即時監控線上環境，發現異常行為（例如某個 API 突然回應時間變長）主動通知，不用等用戶回報。

簡單講，過去你要先用 Playwright 寫測試腳本、測試失敗後人工看 log 找問題、修完再重跑一次——Coldtea 把這三步全部自動化，從「描述測試需求」到「PR 開出來等你審」只需要 5-10 分鐘。

💡 為什麼現在爆紅？時機點剛好：2026 年 Claude Code、Codex、Cursor 等 AI coding agent 已經普及到中小型團隊，但測試這塊還是大部分人手動做或用傳統腳本維護。Coldtea 是第一個把測試生成、執行、修復全部串成閉環的產品。

核心功能拆解

1. 自然語言寫測試（Zero Script）

不需要寫 Playwright / Cypress 腳本，直接用自然語言：

// 在 Coldtea dashboard 輸入
Test: 用戶註冊流程
Steps:
- 打開註冊頁面
- 填入 email、密碼、確認密碼
- 點擊註冊按鈕
- 應該看到「註冊成功」訊息並跳轉到儀表板

// Coldtea 會自動生成並執行測試，回報 pass / fail

如果 fail，Coldtea 會附上截圖、console log、network 請求記錄，並標出可能出錯的步驟。

2. AI Agent 自動修復（整合 Claude Code / Codex）

當測試失敗時，Coldtea 可以自動呼叫你設定的 coding agent：

// Coldtea 偵測到測試失敗
Test failed: Registration button not clickable

// 自動叫 Claude Code 分析
Coldtea → Claude Code: 讀取 /src/components/RegisterForm.tsx
Claude Code 回報：disabled 屬性綁定邏輯有問題，已開 PR #1234 修復

// 你只需要審核 PR，不用自己 debug

3. Production 即時監控

部署到 production 後，Coldtea 會持續跑關鍵流程測試（例如每 10 分鐘測一次登入流程），發現異常立即發 Slack / Discord / Email 通知。過去你可能是等用戶回報才知道出事，現在 Coldtea 比用戶更早發現。

常見問題

Coldtea.ai 是什麼？跟傳統測試工具有什麼不同？

Coldtea.ai 是一套 AI 驅動的 E2E 測試與監控平台，最大差異在於不需要人工寫測試腳本。你只要用自然語言描述要測什麼，Coldtea 會自動生成瀏覽器測試步驟、執行、回報結果，甚至主動建議修復方案。

Coldtea.ai 支援哪些 AI coding agent？

Coldtea 可以直接整合 Claude Code、Codex、OpenCode 等主流 coding agent，讓 agent 自動讀取測試失敗的 log、定位問題程式碼、建議修復方式，甚至直接開 PR。

Coldtea.ai 免費嗎？定價怎麼算？

提供免費試用方案（每月 100 次測試執行），付費方案從 $20/座位/月起，依測試執行次數與監控網站數量計價。適合 2-20 人的開發團隊。

適合哪些團隊使用？

最適合已經在用 Claude Code / Codex / Cursor 等 AI coding agent、想把測試自動化也交給 AI 處理的團隊，尤其是快速迭代的新創與小型開發團隊。

總結：值得現在試嗎？

Coldtea.ai 目前還是剛上線的新產品（8/9 才在 PH 發布），功能穩定性與生態整合還在早期階段，不建議直接用在核心 production 環境。但如果你的團隊已經深度使用 Claude Code 或 Codex，Coldtea 提供的測試自動化閉環是目前市場上少見的體驗，值得先用 Free 方案在小專案試跑 2-4 週，觀察測試生成準確度與 AI 修復品質再決定是否擴大導入。

對台灣的中小型開發團隊來說，Coldtea 最大的吸引力在於降低測試維護成本——過去可能要專門派一個人寫測試腳本、定期更新，現在這塊可以大幅外包給 AI，讓團隊把人力集中在功能開發與用戶體驗優化上。
