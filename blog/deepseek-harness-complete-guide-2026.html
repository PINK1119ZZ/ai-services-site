DeepSeek Harness 是什麼？

2026 年 8 月 13 日，DeepSeek 把一個秘密武器開源了。DeepSeek Harness 是一個以 TypeScript 撰寫的插件式 Coding Agent 框架，基於 Cordis 依賴注入容器，讓你可以像組合積木一樣拼出自己的 AI 開發工作流程——包括把 Claude Code、Codex，甚至 Gemini CLI 當作 sub-agent 來調度。

開源後 8 天內累積超過 165,000 GitHub Stars，超越了 LangChain（144K★）和 Claude Code（142K★）的歷史累積速度，成為 AI 工具圈年度最快速竄紅的開源框架之一。

💡 一句話理解 Harness

如果 Claude Code 是一台全功能 AI 開發助手，那 DeepSeek Harness 是它的 企業版調度系統——你可以定義「哪種任務交給哪個 Agent」，讓多個 AI Coding 工具協同工作，同時統一管理費用與日誌。

插件式架構深度解析（Cordis 框架）

DeepSeek Harness 的核心設計哲學是 「一切皆插件（Everything is a Plugin）」，這和傳統框架（LangChain 的 Chain 鏈式設計、CrewAI 的 Role 角色設計）有根本性不同。

Cordis 依賴注入容器

Harness 採用 Cordis（JavaScript/TypeScript 生態系的輕量 IoC 容器）作為核心。每個功能——包括 AI 模型呼叫、工具執行、記憶體管理——都以 Plugin 形式掛載到同一個 Context 上。

// harness.config.ts 基本結構
import { createApp } from '@deepseek/harness'
import { DeepSeekPlugin } from '@deepseek/harness-provider-deepseek'
import { ClaudeCodePlugin } from '@deepseek/harness-provider-claude'
import { FileSystemPlugin } from '@deepseek/harness-plugin-fs'

const app = createApp()

app.plugin(DeepSeekPlugin, {
  apiKey: process.env.DEEPSEEK_API_KEY,
  model: 'deepseek-v4-pro',
})

app.plugin(ClaudeCodePlugin, {
  // Claude Code 當 sub-agent：處理複雜重構任務
  role: 'refactor-specialist',
})

app.plugin(FileSystemPlugin)

app.start()

三層架構設計

  • Orchestrator Layer（調度層）：決定「任務給誰做」，可基於任務類型、費用、速度動態路由
  • Provider Layer（模型層）：各 AI 模型的統一接口（DeepSeek / Claude / GPT-5 / Gemini）
  • Plugin Layer（擴展層）：工具調用、記憶體、向量搜尋、CI/CD 整合等功能模塊

這個設計讓你可以做到：「日常開發問題交給 DeepSeek V4 Pro（便宜）→ 複雜架構重構交給 Claude Code（準確）→ 文檔生成交給 Gemini（長上下文）」，全部在同一個 CLI 指令下統一觸發。

⚠️ 注意：開源後漲價事件

Harness 開源時宣稱完全免費，但框架本身只是調度層；各 AI 模型 API 費用仍然分開計費。開源後不久 DeepSeek API 曾調整定價約 1,100%（部分方案），目前費用請以官方 API 頁面為準。本文費用計算段落有最新數字。

5 步驟完整安裝教學

Step 1

環境需求確認

Node.js 20+ 與 npm 9+（或 pnpm 8+）。建議使用 nvm 管理 Node 版本。

node --version  # 需要 v20+
npm --version   # 需要 9+
Step 2

建立專案並安裝核心套件

mkdir my-harness-agent && cd my-harness-agent
npm init -y
npm install @deepseek/harness @deepseek/harness-cli
npm install @deepseek/harness-provider-deepseek

如果要整合 Claude Code 作為 sub-agent，額外安裝：

npm install @deepseek/harness-provider-claude
Step 3

設定 API Keys（.env 檔）

# .env（絕對不要 commit 這個檔案！）
DEEPSEEK_API_KEY=sk-xxxxxxxxxxxxxxxx
ANTHROPIC_API_KEY=sk-ant-xxxxxxxxxxxx   # 若使用 Claude sub-agent
OPENAI_API_KEY=sk-xxxxxxxxxxxxxxx       # 若使用 GPT sub-agent
Step 4

建立 harness.config.ts

import { createApp } from '@deepseek/harness'
import { DeepSeekPlugin } from '@deepseek/harness-provider-deepseek'
import { FileSystemPlugin } from '@deepseek/harness-plugin-fs'
import { GitPlugin } from '@deepseek/harness-plugin-git'

const app = createApp({
  workspace: process.cwd(),
  maxConcurrency: 3,
  logging: { level: 'info' },
})

app.plugin(DeepSeekPlugin, {
  apiKey: process.env.DEEPSEEK_API_KEY!,
  model: 'deepseek-v4-pro',
  promptCachingEnabled: true,  // 重要：開啟 prompt caching 省費用
})

app.plugin(FileSystemPlugin)
app.plugin(GitPlugin)

export default app
Step 5

第一次執行

# 啟動互動模式
npx harness run --config harness.config.ts

# 或直接下任務指令
npx harness task "分析 src/ 目錄所有 TypeScript 檔案，找出潛在的 null safety 問題"

# 查看費用統計
npx harness stats --session last

初次執行時 Harness 會自動掃描工作目錄建立 code index，大型專案（10 萬行以上）需要 2-5 分鐘。

把 Claude Code 當 Sub-Agent：實戰配置

這是 Harness 最獨特的功能：模型路由（Model Routing）。你可以定義規則，讓不同類型的任務自動路由到不同的 AI 工具。

// harness.config.ts — 進階路由設定
import { createApp, RoutingPlugin } from '@deepseek/harness'
import { DeepSeekPlugin } from '@deepseek/harness-provider-deepseek'
import { ClaudeCodePlugin } from '@deepseek/harness-provider-claude'

const app = createApp({ workspace: process.cwd() })

// 主力：DeepSeek V4 Pro（便宜，1M context）
app.plugin(DeepSeekPlugin, {
  apiKey: process.env.DEEPSEEK_API_KEY!,
  model: 'deepseek-v4-pro',
  role: 'primary',
})

// Sub-agent：Claude Code（複雜重構/架構設計）
app.plugin(ClaudeCodePlugin, {
  apiKey: process.env.ANTHROPIC_API_KEY!,
  model: 'claude-sonnet-4-5',
  role: 'refactor-specialist',
})

// 路由規則
app.plugin(RoutingPlugin, {
  rules: [
    {
      match: { taskType: 'refactor', complexity: 'high' },
      target: 'refactor-specialist',  // → Claude Code
    },
    {
      match: { taskType: ['debug', 'explain', 'generate-test'] },
      target: 'primary',  // → DeepSeek V4 Pro（省錢）
    },
  ],
  fallback: 'primary',
})

export default app

💰 路由策略帶來的費用節省

實測：一個中型 Node.js 專案（約 50K 行）一個月的 coding agent 使用量，用純 Claude Code 約 $80-120/月，改用 Harness 路由（80% DeepSeek + 20% Claude）後降至 $18-32/月，省下 60-75%。

常見問題 FAQ

Q：DeepSeek Harness 和 DeepSeek Reasonix 有什麼不同？
A：Harness 是 DeepSeek 官方開源的 AI Agent 調度框架；Reasonix（34.6K★）是社群驅動的第三方工具，專注於 prompt caching 費用優化。兩者可以搭配使用，Harness 負責任務調度，Reasonix 套件可作為 Harness plugin 優化費用。功能重疊但定位不同。
Q：需要會 TypeScript 才能用嗎？
A：配置檔用 TypeScript（.ts），但型別系統非常直觀，即使你主要是 Python / Go / PHP 開發者，依照本文範例修改變數名稱即可上手。進階插件開發才需要深度 TypeScript 知識。
Q：資料安全性如何？DeepSeek 是中國公司，我的程式碼會被保留嗎？
A：這是台灣開發者最常問的問題。Harness 框架本身在本地端運行，程式碼片段會透過 API 傳送給你選擇的 AI 模型。如果使用 DeepSeek V4 API，資料確實會傳到 DeepSeek 伺服器（中國監管）。解決方案：敏感專案可將路由設定為 100% Claude 或 GPT（歐美資料中心），只讓非敏感任務用 DeepSeek 省費。
Q：VS Code / JetBrains / Neovim 有沒有整合？
A：目前官方提供 CLI 為主，VS Code Extension 在 Roadmap 中（預計 Q4 2026）。暫時可透過 VS Code 內建終端機執行 Harness CLI，或配合 tmux 在後台掛 session。
Q：Harness 和 Claude Code 直接對比，哪個更好？
A：不同使用場景有不同答案。單機個人使用：Claude Code 更直觀，開箱即用。多模型費用優化：Harness 明顯勝出（省 60-75%）。CI/CD 整合：Harness 更靈活（支援 GitHub Actions / GitLab CI 插件）。企業多人協作：Harness 集中管理費用和日誌更有優勢。
Q：165K★ 爆紅後會不會變成另一個過度炒作的框架？
A：合理的顧慮。不過 Harness 的星數增速部分確實有社群炒作成分（DeepSeek 品牌效應）。我建議以 能否解決你的具體痛點 為判斷標準：如果你有多 AI 模型費用管理需求，它是目前最成熟的開源方案。如果只是一般 coding 助手需求，Claude Code 或 Kilo Code 更省事。
