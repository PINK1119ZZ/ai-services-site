Grok 4.7 是什麼？為什麼重要？

2026 年 9 月 21 日，xAI 正式發布 Grok 4.7，這是繼 Grok 4.6（2026 年 8 月）之後最快的一次大版本跳躍。相比 Grok 4.6 的 1.5T 參數，Grok 4.7 直接跳升至 2.1T 參數（+40%），在 Artificial Analysis 的 Intelligence Index 達到 46 分，全球排名 #4，超越了 GPT-5.6 Sol，僅次於 Claude Fable 5.1、GPT-6 Astra 和 DeepSeek V4 Ultra。

💡 重要背景：xAI 最初規劃的 Grok 4.7 是「Grok 4.8 的過渡版本」，但實際測試結果遠超預期——三個 benchmark 奪下全球第一，特別是在電工和法律推理領域，Grok 4.7 已經超越了所有現有競爭對手。

對台灣開發者來說，Grok 4.7 的最大意義在於：如果你的應用場景涉及工程計算、法律文件分析、技術規格解讀，Grok 4.7 現在是性價比最高的選擇——相同的 $2/$6 定價，但推理能力大幅提升。

Grok 4.7 API 接入教學（10 分鐘上手）

Grok 4.7 使用 xAI API，完全兼容 OpenAI SDK，幾乎零遷移成本。

步驟一：申請 xAI API Key

前往 console.x.ai 註冊帳號，支援信用卡付款，台灣可直接使用。新用戶通常有免費額度可試用。

步驟二：Python 快速整合

Python（使用 OpenAI SDK）
pip install openai
from openai import OpenAI

# 只需更換 base_url 和 api_key，其他完全相同
client = OpenAI(
    api_key="xai-你的-API-KEY",
    base_url="https://api.x.ai/v1"
)

response = client.chat.completions.create(
    model="grok-4.7",
    messages=[
        {
            "role": "system",
            "content": "你是一位專業的工程顧問，精通電氣工程與法律分析。"
        },
        {
            "role": "user",
            "content": "請分析以下電路設計的安全合規問題..."
        }
    ],
    max_tokens=2000,
    temperature=0.1  # 技術分析建議低溫度
)

print(response.choices[0].message.content)

步驟三：Node.js 版本

Node.js / TypeScript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: process.env.XAI_API_KEY,
  baseURL: 'https://api.x.ai/v1',
});

async function analyzeDocument(documentText: string) {
  const response = await client.chat.completions.create({
    model: 'grok-4.7',
    messages: [
      {
        role: 'system',
        content: '你是一位台灣法律文件分析專家，請用繁體中文回答。'
      },
      {
        role: 'user',
        content: `請分析以下合約條款的法律風險：\n\n${documentText}`
      }
    ],
    max_tokens: 3000,
    temperature: 0.05,
  });

  return response.choices[0].message.content;
}

// 使用範例
const result = await analyzeDocument(contractText);
console.log(result);

步驟四：串流（Streaming）模式

Python 串流模式（適合長輸出）
stream = client.chat.completions.create(
    model="grok-4.7",
    messages=[
        {"role": "user", "content": "請詳細分析這份電路圖的安全問題..."}
    ],
    stream=True,
    max_tokens=4000
)

for chunk in stream:
    if chunk.choices[0].delta.content is not None:
        print(chunk.choices[0].delta.content, end="", flush=True)

print()  # 換行

Grok 4.7 的限制與注意事項

  • ⚠️ 程式碼生成弱：Coding Agent Index 61.4%，不適合作為主力 Coding Agent（用 Claude Fable 5.1 更好）

常見問題 FAQ

❓ Grok 4.7 和 Grok 4.6 有什麼差別？
Grok 4.7 參數量從 1.5T 提升至 2.1T（+40%），Intelligence Index 從 #6 躍升至 #4 全球。主要改進在電工、法律、科學推理三個領域拿下全球第一。定價維持 $2/$6 per MTok 不變。
❓ Grok 4.7 的定價是多少？台灣可以用嗎？
輸入 $2/MTok，快取 $0.50/MTok，輸出 $6/MTok。台灣可直接在 console.x.ai 申請 API key，使用信用卡付款，無需 VPN。
❓ Grok 4.7 和 Claude Fable 5.1 哪個更好？
取決於用途。程式碼/創意寫作：Claude Fable 5.1 勝出。電工/法律/科學推理：Grok 4.7 全球第一。成本面：Grok 4.7 輸出 $6/MTok 比 Claude 的 $15/MTok 便宜 60%。
❓ Grok 4.7 API 如何快速接入現有 OpenAI 應用？
只需兩個改動：將 client 的 base_url 改為 "https://api.x.ai/v1"，api_key 改為你的 xAI API key，model 改為 "grok-4.7"。其他 SDK 呼叫完全不用改。
❓ Grok Voice Transcribe 2.0 是什麼？
與 Grok 4.7 同日發布的語音轉文字模型，多語言（含繁中/台語）辨識大幅改善，$0.006/分鐘，與 xAI API 統一管理。適合語音 AI 應用開發者建立端對端 pipeline。
❓ Grok 4.7 支援繁體中文嗎？
支援，但繁中品質不如 Claude Fable 5.1 穩定。對於繁中文件分析（法律、工程），建議在 system prompt 明確指定「請用繁體中文回答，避免簡體字」，效果會更好。
