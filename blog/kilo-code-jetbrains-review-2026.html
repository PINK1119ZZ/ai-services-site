Kilo Code 是什麼？開源定位解析

你可能用過 Cursor、試過 Claude Code、甚至折騰過 GitHub Copilot 的 Agent Mode。但 Kilo Code 的定位截然不同：它是 Roo Code 的 fork，由 Anaconda（AI 資料科學工具龍頭）背書，MIT 開源，強調一件事 — 不從 API 費用上賺你任何一分錢。

2026 年 9 月 1 日，Kilo Code 完成了兩件大事：

  • JetBrains 版本正式釋出（v7.1.5，IntelliJ/WebStorm/PyCharm/GoLand/Rider 全支援）
  • PH 9/1 日榜 #1（489 upvotes，產品獵人社群認可）

加上原本的 VS Code 版本，Kilo Code 目前累計已有 3M+（300 萬）用戶，GitHub repo（kilo-org/kilocode）持續活躍，1,157 位 contributors 共同維護。

🔑 Kilo Code 核心主張：
「你自帶 API key，我們不賺中間差價。500+ 模型（Claude、GPT-5.4、Gemini、DeepSeek、Qwen…）想用哪個用哪個，zero markup。」

這不只是行銷話術。市面上大多數 AI coding 工具（包含 Cursor Pro）都在底層收取模型費用的加成 — 有時高達 20-50%。Kilo Code 選擇完全不收，依靠 Kilo Pass 訂閱收取基本平台費。

和 Roo Code 的關係

Kilo Code 是從 Roo Code 分叉出來的，而 Roo Code 本身是從 Cline（另一個開源 Claude Code 替代品）演化而來。這條開源血脈讓 Kilo Code 繼承了非常完整的工具呼叫（tool calling）架構，並加入了 Anaconda 企業級的安全與合規設計。

PR review 從此不用跳出 IDE。Kilo Code 可以直接在你的 JetBrains IDE 裡顯示 PR diff，並讓 agent 針對每個 change chunk 給出解釋和建議。

5 步驟安裝教學（JetBrains Plugin Marketplace）

1 開啟 JetBrains IDE，進入 Plugin Marketplace
File → Settings → Plugins（Mac：IntelliJ IDEA → Preferences → Plugins）
2 搜尋「Kilo Code」並安裝
在 Marketplace 搜尋框輸入 Kilo Code，點擊 Install，等待下載（約 30MB）。
3 重啟 IDE 並開啟 Kilo Code 面板
安裝後 IDE 右側會出現 Kilo Code 圖示（⚡）。點擊開啟設定面板。
4 設定 API Provider
點選 Settings → AI Provider。選擇你的 Provider（Anthropic、OpenAI、Google、Bedrock、Vertex AI、或 OpenRouter 等），輸入 API Key。

推薦設定（台灣開發者）： 
Provider: Anthropic
API Key: sk-ant-xxxxxxxx
Model: claude-sonnet-5-20260901
Fallback Model: deepseek-v4-pro（省費備選）
5 測試第一個指令
在 Kilo Code 面板輸入：「解釋這個函數的功能，並幫我寫單元測試」，然後在編輯器中選取一段程式碼。若能正確回應，代表安裝成功 🎉
⚠️ JetBrains 版本限制（v7.1.5）：
部分舊版 JetBrains IDE（2024.1 以前）可能有相容性問題。建議更新到 2024.3 或以上。DataGrip 的 SQL 自動補全功能需額外啟用「SQL Context Mode」。

FAQ 常見問題

Q1：Kilo Code 和 Roo Code、Cline 有什麼關係？
Kilo Code 是 Roo Code 的 fork，而 Roo Code 源自 Cline。三者都是 MIT 開源，共享底層工具呼叫架構。Kilo Code 的主要差異是由 Anaconda 背書的企業級安全設計，以及更積極的 JetBrains 支援和 Zero Markup 商業模式。
Q2：Kilo Pass $19/月 包含多少 API 用量？
Kilo Pass 包含的具體 token 額度請以官方最新說明為準（kilocode.ai/pricing）。購買前建議先用 BYOK 免費方案跑一個月，瞭解自己實際的 API 用量，再決定是否值得切換 Kilo Pass。
Q3：Kilo Code 支援繁體中文介面嗎？
目前 Kilo Code 介面主要為英文。但對話可以用繁中輸入，AI 回覆也可以要求用繁中。JetBrains 本身的中文化支援不受影響。
Q4：用 BYOK 模式，Kilo Code 會儲存我的程式碼嗎？
BYOK 模式下，你的程式碼直接從你的 IDE 傳送到你選擇的 API provider（Anthropic/OpenAI/Google 等），不經過 Kilo Code 的伺服器。Kilo Code 本身只儲存設定，不碰程式碼內容。對隱私要求最高的情況，搭配本機 Ollama 模型可達到完全離線。
Q5：JetBrains 版本的並行 Agent 有什麼限制？
v7.1.5 的並行 Agent 在 BYOK 模式下可同時開多個，但 Kilo Pass 方案有額外的並行配額優惠。目前 JetBrains 版本的並行 Agent UI 還在持續優化中，多個 agent 同時修改同一個檔案時需手動處理 merge conflict。
Q6：從 Cursor 切換到 Kilo Code 難嗎？
如果你目前用 Cursor（VS Code 版），切換到 Kilo Code for VS Code 相對容易 — 設定好 API key，工作流幾乎一樣。切換到 JetBrains 版本需要先適應 JetBrains 的 Plugin 架構，但安裝步驟只要 5 分鐘。最大的調整是習慣自己管理 API key（如果你目前用 Cursor 的包含方案）。
