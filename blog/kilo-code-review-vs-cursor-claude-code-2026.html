🔍 Kilo Code 是什麼？

Kilo Code（官網：kilo.ai）是一個以 MIT 授權開源的 AI Coding Agent，核心定位是「一個 Agent，跑在你所有的開發環境裡」。它支援 VS Code、JetBrains（IntelliJ / WebStorm / PyCharm 等）、CLI 和雲端 Agent，背後透過統一引擎運行，讓你的上下文不會在切換環境時斷掉。

  • 10 兆+ tokens / 月：實際使用量驚人，背後有完整的推論基礎設施支撐

⚠️ Kilo Code 不是 Cursor 的「便宜複製品」

許多人第一眼以為 Kilo Code 只是便宜版 Cursor。實際上，它的架構設計思路完全不同：Kilo Code 不鎖定自家推論雲，讓你帶自己的 API key（BYOK），零加成費用。開放程度更接近 Cline，但多出了 Orchestrator、Agent Manager、KiloClaw 雲端 Agent 等進階功能。

🎯 Kilo Code 的五大核心模式

Kilo Code 把不同的 AI Coding 情境拆成五個可切換的模式，這是它最被低估的設計之一：

1

Code Mode — 主力日常 Coding

寫新功能、修 Bug、重構既有程式碼。理解整個 codebase 上下文，一次可以跨多個檔案修改。這是 90% 使用者最常用的模式。

2

Architect Mode — 先規劃再動手

在開始寫程式之前，先讓 Kilo Code 幫你規劃功能架構、梳理依賴關係、討論技術選型。避免先寫再重寫的悲劇。

3

Ask Mode — 快速問答，不動程式碼

只想問問題，不想讓 AI 直接改檔案？Ask Mode 進入純對話模式，適合理解程式碼邏輯、查文件、快速 Debug 思路。

4

Orchestrator Mode — 多 Agent 並行執行（⭐ 殺手功能）

這是 Kilo Code 2026 年最強的新功能。Orchestrator 可以把一個大任務拆成多個子任務，同時派給多個子 Agent 執行。舉例：「重構整個 API 層」這種任務，Orchestrator 會同時讓多個子 Agent 分別處理不同的 API 模組，最後合併結果。速度大幅提升。

5

Debug Mode — 聚焦 Bug 修復

專門為 Debug 優化的模式。自動讀取錯誤日誌、堆疊追蹤，縮小問題範圍，比在 Code Mode 裡手動貼 error message 有效率多了。

⚡ 安裝 Kilo Code：5 分鐘完整設置

VS Code 安裝（最多人用）

1

從 VS Code Marketplace 安裝

在 VS Code 的 Extensions 面板搜尋 Kilo Code，或直接執行：

ext install kilocode.kilo-code

如果你用的是 Cursor、Windsurf 等 VS Code fork，可以從 Open VSX 安裝。

2

設定 API Provider

點開側邊欄的 Kilo Code 圖示，進入 Settings → API Provider。選擇你的模型供應商並貼上 API Key：

# Anthropic（Claude 系列）
ANTHROPIC_API_KEY=sk-ant-xxxxxxxx

# OpenAI（GPT 系列）
OPENAI_API_KEY=sk-proj-xxxxxxxx

# 或選擇 OpenRouter（統一入口，500+ 模型）
OPENROUTER_API_KEY=sk-or-xxxxxxxx
3

選擇預設模型

建議初學者從 claude-sonnet-4-5 或 gpt-5.4 開始。進階使用者可以設定 Auto Efficient 路由，讓 Kilo Code 自動根據任務複雜度選模型，節省費用。

4

開啟第一個 Coding 任務

按下 Cmd/Ctrl + Shift + P，輸入 Kilo Code: Open Panel，或直接點側邊欄圖示。在 Chat 框輸入你的需求，Kilo Code 會分析你的 codebase 並開始作業。

5

（進階）設定 Orchestrator

在 Kilo Code 設定中啟用 Orchestrator Mode，設定子 Agent 數量上限（建議 2-4 個，避免 API 費用暴增）。適合大型 PR 或跨模組重構任務。

JetBrains 安裝

前往 Settings → Plugins → Marketplace，搜尋 Kilo Code。Sep 1, 2026 GA 的版本是完全原生重寫，非移植版，支援 IntelliJ IDEA、WebStorm、PyCharm、GoLand 等全系列。

❓ Kilo Code 常見問題 FAQ

Q：Kilo Code 真的完全免費嗎？有什麼隱藏費用？
個人版（Individual plan）是免費的，平台本身不收費。你只需要支付你自己使用的 AI 推論費用（API Key）。如果你選用 Kilo Pass 而非 BYOK，Kilo Code 會在 API 費用上加 5% 手續費作為服務費。Teams 方案 $15/人/月，Enterprise 洽詢報價。
Q：Kilo Code 和 Cline 有什麼不一樣？
兩者都是開源的 VS Code AI Coding Agent，架構上有相似之處。主要差異：Kilo Code 多了 JetBrains 原生支援、Orchestrator 多 Agent 模式、KiloClaw 雲端 Agent、Agent Manager 可視化管理，以及 Teams/Enterprise 商業方案。Cline 則更輕量，對新手較友善。Kilo Code Teams $15/月 也比 Cline Teams $20/月 便宜。
Q：Orchestrator Mode 適合什麼情況使用？
適合大型任務：大範圍重構（如把 Express 換成 Fastify）、跨模組新功能開發、大量 test 生成、程式碼文件化等。Orchestrator 會把主任務拆成子任務並同時跑多個子 Agent，整體速度比單一 Agent 快很多。建議子 Agent 上限設 2-4 個，太多會讓 API 費用暴增。
Q：Kilo Code 的程式碼資料安全嗎？
Kilo Code 完全開源，你可以審計所有 prompt 邏輯，沒有黑盒疑慮。使用 BYOK 時，你的程式碼直接透過你自己的 API Key 送到模型供應商（Anthropic/OpenAI 等），Kilo Code 不會在中間留存。若完全不想資料出公司，可以搭配 Ollama 等本機模型。
Q：JetBrains 版本成熟嗎？還是建議用 VS Code 版本？
JetBrains 版本在 2026 年 9 月 1 日才 GA，是從頭原生開發的（不是移植），整體穩定性高。但部分進階功能仍在追趕 VS Code 版本。如果你原本就用 IntelliJ / WebStorm，直接安裝 JetBrains 版本即可，不需要強制換到 VS Code。
Q：如何用 OpenRouter 連接到 500+ 模型？
在 Kilo Code Settings → API Provider 選擇 OpenRouter，貼上你的 OpenRouter API Key（去 openrouter.ai 免費申請）。OpenRouter 聚合了 Anthropic、OpenAI、Google、Meta、Mistral 等所有主流模型，你在 Kilo Code 裡選模型時就能看到完整清單。費用按 OpenRouter 的 Provider 費率計算，不額外加成。

🏁 結論：Kilo Code 值得換嗎？

如果你現在用的是 Cursor 或 Claude Code，Kilo Code 是值得認真考慮的替代選項，尤其是以下幾種情況：

  • 你用 JetBrains 系 IDE，不想換到 VS Code 系的 Cursor 或 Windsurf
  • 你有小團隊（2-10 人），Teams $15 vs Cursor Teams $40 差距很大

  • 你已有 API Key，不想再付固定月費，BYOK 零成本更划算
  • 你需要 Orchestrator 多 Agent 並行處理大型任務

如果你是終端機重度使用者、需要最深的多輪重構能力，Claude Code Max 可能仍是更強的選擇。但從性價比和開放性綜合來看，Kilo Code 在 2026 年是最值得試試的開源 AI Coding Agent。
