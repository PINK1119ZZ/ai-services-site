MoneyPrinterTurbo 是什麼？

MoneyPrinterTurbo 是一個開源的 AI 短影音自動化生成工具。它的整個工作流程如下：

⌨️
輸入關鍵字或主題 例如：「台北必吃10大小吃」、「Python 學習技巧 2026」
↓
✍️
AI 劇本生成 使用 Claude / GPT-5.4 / Kimi 自動撰寫 60-180 秒分段劇本
↓
🎙️
AI TTS 配音 MiniMax H3（繁中效果最佳）、Azure TTS、OpenAI TTS 可選
↓
🎬
素材搜尋與剪輯 自動從 Pexels / Pixabay / 本地素材庫 搜尋配圖/影片，自動剪輯
↓
📝
字幕生成 自動從 TTS 音檔生成對齊字幕（SRT），可自訂字型、顏色、位置
↓
🎥
最終輸出 9:16 豎版 MP4（適合 Shorts/Reels/TikTok），可選 1080p 或 4K

整個過程在本地電腦執行，生成一支 60 秒影片通常需要 3-8 分鐘（取決於素材搜尋速度和 TTS 服務）。

🔧 MoneyPrinterTurbo 技術棧

  • 後端框架：Python 3.10+，FastAPI，非同步任務佇列
  • 前端介面：Web UI（Streamlit），也有 CLI 模式
  • 影片剪輯：FFmpeg（本地）+ MoviePy
  • LLM 劇本：支援 Claude、GPT-5.4、Kimi（月之暗面）、Qwen、Ollama 本地
  • TTS 語音：MiniMax H3（推薦繁中）、Azure TTS、OpenAI TTS、Edge TTS（免費）
  • 素材來源：Pexels API、Pixabay API、本地資料夾
  • 字幕：Whisper（本地離線 STT 反推字幕）或 TTS 時間戳對齊
  • 授權：Apache 2.0（開源商用）

5 步驟完整安裝教學

1

安裝系統依賴：Python 3.11 + FFmpeg

MoneyPrinterTurbo 需要 FFmpeg 做影片剪輯，這是最重要的前置安裝：

# macOS（Homebrew） brew install python@3.11 ffmpeg imagemagick # Ubuntu / Debian sudo apt update sudo apt install python3.11 python3.11-venv ffmpeg imagemagick -y # Windows（以管理員身份執行 PowerShell） winget install Python.Python.3.11 winget install Gyan.FFmpeg # 或從 https://www.gyan.dev/ffmpeg/builds/ 手動安裝並加入 PATH
2

Clone 專案並安裝 Python 套件

# Clone MoneyPrinterTurbo git clone https://github.com/harry0703/MoneyPrinterTurbo cd MoneyPrinterTurbo # 建立虛擬環境 python3.11 -m venv venv source venv/bin/activate # Windows: venv\Scripts\activate # 安裝套件（含所有依賴） pip install -r requirements.txt # 驗證安裝 python -c "import moviepy; print('MoviePy OK')" ffmpeg -version | head -1 # 應輸出 ffmpeg version 7.x
3

設定 config.toml：API Keys 與語言偏好

複製範例設定檔並填入你的 API Keys：

cp config.example.toml config.toml # 用你的編輯器開啟： nano config.toml # 或 code config.toml（VS Code）

config.toml 最重要的設定段：

# config.toml 關鍵設定 [llm] # 劇本生成 LLM（擇一） provider = "claude" # 推薦：品質最好 api_key = "sk-ant-xxxxxxxx" model = "claude-sonnet-5-20261001" language = "zh-TW" # 繁體中文劇本 [tts] # TTS 語音（繁中推薦 MiniMax H3） provider = "minimax" api_key = "你的 MiniMax API Key" voice_name = "female-zh-TW-warm" # 台灣女聲（自然溫暖） # 備選免費方案： # provider = "edge-tts" # voice_name = "zh-TW-HsiaoChenNeural" # 微軟台灣女聲（免費） [video] video_aspect = "9:16" # YouTube Shorts / IG Reels / TikTok # video_aspect = "16:9" # YouTube 橫版 video_fps = 30 video_resolution = "1080x1920" # 1080p 豎版 [stock] # 素材來源（需申請免費 API） pexels_api_key = "你的 Pexels API Key" pixabay_api_key = "你的 Pixabay API Key" # 或使用本地素材（比較快） local_videos_path = "./materials/videos/"
4

啟動 Web UI，生成第一支影片

# 啟動 Web UI（預設 http://localhost:8501） python webui.py # 或使用 CLI 模式（批次生成） python main.py \ --subject "台北必吃10大小吃攻略" \ --duration 60 \ --language zh-TW \ --voice female-zh-TW-warm \ --output ./output/taipei-food.mp4

Web UI 開啟後，在「影片主題」欄位輸入你的主題，點擊「生成影片」。第一次生成約 5-10 分鐘（需下載字型和 Whisper 模型）。

5

進階：批次生成與自動上傳

MoneyPrinterTurbo 支援從 CSV 批次生成多支影片，適合自動化內容農場：

# topics.csv 格式： # subject,duration,language,output_name "台北夜市美食TOP10",60,zh-TW,taipei-night-market.mp4 "Python 入門 5 大技巧",90,zh-TW,python-tips.mp4 "Claude Code vs Cursor 誰更強",120,zh-TW,claude-vs-cursor.mp4 # 批次執行 python batch.py --input topics.csv --output ./output/ # 搭配 cron 每天自動生成（Linux/macOS） 0 6 * * * /path/to/venv/bin/python /path/to/batch.py --input /daily-topics.csv

MiniMax H3 繁中配音設定詳解

申請 MiniMax API

  1. 前往 platform.minimaxi.com 註冊（支援 Google 帳號登入）

  3. 在 API Keys 頁面建立金鑰，複製填入 config.toml

常見問題 FAQ

Q1：Windows 可以用嗎？還是要 Mac/Linux？

A：Windows 10/11 可以使用，但建議在 WSL2（Windows Subsystem for Linux，Ubuntu 22.04）環境下安裝，可以避免大多數 Python 套件相容性問題。純 Windows 安裝也可以，但 FFmpeg 的 PATH 設定需要特別注意。MacOS 是最順暢的環境。

Q2：生成的影片可以商業使用（上傳 YouTube 賺廣告費）嗎？

A：MoneyPrinterTurbo 程式碼本身是 Apache 2.0 可商用。但注意素材版權：若使用 Pexels/Pixabay 素材，需確認每個素材的授權（Pexels 所有素材免費商用；Pixabay 大多數可免費商用，少數需標註）。AI 生成的劇本和配音不涉及版權問題。建議建立一個「素材版權記錄表」追蹤每支影片使用的素材。

Q3：每支影片生成需要多久？能加速嗎？

A：基本配置（Core i7 筆電，無 GPU）約 5-10 分鐘/支。最大的瓶頸是素材搜尋（網路速度）和 FFmpeg 剪輯（CPU）。加速方法：1) 預先下載素材庫到 local_videos_path（省去 API 請求時間）；2) 使用雲端 VPS（DigitalOcean 2vCPU）讓電腦繼續做別的事；3) 多開幾個 MoneyPrinterTurbo 實例並行執行不同任務。

Q4：繁體中文劇本品質怎麼樣？會不會有簡體字混入？

A：設定 language = "zh-TW" 並使用 Claude 作為 LLM 時，繁體中文效果非常好，幾乎不會出現簡體字。若使用 Kimi 或 Qwen 本地模型，偶爾可能出現簡體字混入，可在 prompt 中加入「請全程使用台灣繁體中文，禁止使用簡體字和中國大陸用語」來修正。

Q5：AI 配音聽起來自然嗎？會很機器人感嗎？

A：MiniMax H3 的繁中配音在 2026 年已經相當自然，情緒波動和語調基本符合人類說話習慣。Edge TTS（微軟免費版）明顯有點機器感。若要求最高品質，可以考慮 ElevenLabs 的 TTS 介面（MoneyPrinterTurbo 有 ElevenLabs 插件，但費用較高）。

Q6：我沒有程式背景，安裝會很難嗎？

A：相對 Cursor 或 Claude Code，MoneyPrinterTurbo 的安裝需要更多指令操作（pip install、FFmpeg 設定）。但只要按照本文步驟一步一步來，沒有程式背景的人通常 1-2 小時內可以完成安裝並生成第一支影片。遇到錯誤時，把錯誤訊息貼給 Claude 詢問通常能快速解決。
