這個模板包是什麼？

n8n 的視覺化介面很直覺，但從零建立一個穩定運行的 Claude Code 整合 workflow 往往需要花 2-4 小時：設定 HTTP Request 節點、處理 API 認證、調整 prompt 格式、處理錯誤情況……每一個細節都可能讓你卡關。

這個模板包解決的就是這件事。5 個 workflow 全部以 n8n 標準 JSON 格式打包，可直接透過「Import Workflow」一鍵匯入，不需要手動複製節點或查文件。每個 workflow 都附有繁中 README 說明設定步驟，從 API key 填入到測試執行，完整走一遍不超過 10 分鐘。

⚡ 核心差異：這不是 prompt 清單，也不是截圖教學。是可直接執行的 n8n JSON，匯入後填入你的 API key 就能跑。台灣市場零競品，英文競品定價 $29-79。

5 個 Workflow 詳解

WF 01

GitHub PR → Claude 摘要 → LINE Notify

當有新 PR 開啟或更新時，自動觸發 Claude 分析程式碼變更，生成繁中摘要（變更目的、潛在風險、建議檢查點），發送至指定 LINE 群組。適合有多人協作但沒有 code review 文化的台灣小團隊。

節點組成：GitHub Webhook → HTTP Request (Claude API) → LINE Notify

WF 02

Claude 生成文章 → 自動發布 GitHub Pages + Facebook 貼文

輸入主題關鍵字，Claude 自動生成 2,000 字繁中文章，透過 GitHub API 推送至 Pages repo，同時生成 Facebook 原生摘要貼文（符合本站 12:00 UTC 發布格式）。適合內容創作者或部落客批量生產。

節點組成：Schedule / Manual Trigger → HTTP Request (Claude) → GitHub API → Facebook Graph API

Claude APIGitHub APIFacebook內容自動化
WF 03

表單潛客 → Claude 分類高/中/低 → Notion 存檔 + 自動回信

收到表單提交（Typeform / Google Form webhook）後，Claude 根據填寫內容自動判斷潛客意向分級（高/中/低），寫入 Notion 資料庫，並依分級發送對應的自動回信。省去業務手動篩選的時間。

節點組成：Webhook → HTTP Request (Claude) → Notion → Gmail / SMTP

Claude APINotionGmail潛客管理
WF 04

LINE Bot 接收訊息 → Claude 智慧回覆

LINE Bot 收到用戶訊息後，透過 Claude API 生成上下文感知回覆，支援多輪對話記憶（透過 Airtable 儲存對話歷史）。適合中小企業客服自動化、FAQ 機器人、內部知識庫查詢。

節點組成：LINE Webhook → Airtable (讀取歷史) → HTTP Request (Claude) → LINE Reply API → Airtable (寫入歷史)

LINE BotClaude APIAirtable多輪對話
WF 05

每日 GitHub Trending → Claude 整理摘要 → Telegram 推送

每天早上 8:00（台灣時間）自動抓取 GitHub Trending 前 10 個 repo，Claude 分析並生成繁中重點摘要（專案用途、適用對象、值不值得關注），推送至 Telegram 頻道或個人。不再錯過每日爆量開源專案。

節點組成：Schedule Trigger → HTTP Request (GitHub) → HTTP Request (Claude) → Telegram Bot

10 分鐘快速上手流程

Step 1 — 解壓縮模板包（1 分鐘）

解壓後你會看到 workflows/ 資料夾（5 個 JSON 檔）、README.md（完整繁中說明）、QUICKSTART.md（本流程精簡版）。

Step 2 — 匯入 Workflow（2 分鐘）

在 n8n 介面點擊右上角 + → Import from file，選擇你要使用的 JSON 檔。Workflow 所有節點會自動載入，已預設好正確的節點連線與設定。

Step 3 — 填入 API Credentials（5 分鐘）

每個 workflow 中需要填入 API key 的節點都已用 {{ YOUR_KEY_HERE }} 標記。依照 README 說明，在 n8n 的 Credentials 設定頁填入對應的 key，回到 workflow 選擇已設定的 credential 即可。

Step 4 — 測試執行（2 分鐘）

點擊 Test Workflow 觸發一次手動執行。查看每個節點的輸出是否符合預期。README 中附有常見錯誤排查說明（最常見：API key 格式錯誤、LINE Channel Access Token 過期）。

Step 5 — 啟用排程（完成）

確認測試無誤後，點擊右上角 Active 開關啟用 workflow。WF 05 的 Schedule Trigger 會在每天 08:00 台灣時間自動執行。

常見問題

模板包是什麼格式？可以直接用嗎？

包含 5 個標準 n8n JSON 檔案，可直接透過 n8n 的「Import Workflow」功能匯入，不需要手動複製節點。每個 JSON 都附有完整繁中 README 說明前置需求與設定步驟。

n8n 需要付費嗎？

n8n 開源版可自架完全免費。架在 DigitalOcean $6/月 Droplet 上即可穩定運行所有 5 個 workflow，是最省成本的做法。n8n Cloud 有免費試用方案，也適合快速測試。

Claude API 用量大概多少？

5 個 workflow 的 API 用量依使用頻率而定。以 WF 05（每日 GitHub Trending）為例，每次執行約消耗 2,000-4,000 tokens（Claude Haiku 約 $0.001/次）。WF 01 和 WF 04 的用量視 PR 大小和對話長度而定，一般月費控制在 $3-10 以內。

5 個 workflow 需要全部用嗎？

不需要。每個 workflow 完全獨立，你可以只匯入你需要的那幾個。5 個都在同一個 zip 檔案裡，買了就全部拿到，想什麼時候用什麼時候匯入。

可以修改 workflow 嗎？

完全可以。JSON 格式讓你可以在 n8n 介面中自由調整每個節點的設定、新增條件邏輯或串接其他服務，不限制使用方式。修改後可以重新匯出 JSON 備份你的自訂版本。

購買後如何下載？

透過 Gumroad 購買後，會立即收到下載連結和收據 email。下載 zip 檔案解壓縮即可取得所有 workflow JSON 和說明文件。
