OfficeCLI 完整教學：用 Claude Code 自動化 Excel、Word、PPT 操作 (2026)

發布日期：2026 年 7 月 10 日 | 更新日期：2026 年 7 月 10 日

想讓 Claude AI 自動處理 Excel 資料、生成 Word 報表、製作 PowerPoint 簡報嗎？OfficeCLI 是一個開源 MCP Server，讓 Claude Code 能直接操作 Microsoft Office 文件，10 分鐘即可上手。本文提供完整教學，從安裝、設定到實際應用，幫助上班族、資料分析師、行銷人員大幅提升辦公效率。

什麼是 OfficeCLI？

OfficeCLI 是一個基於 Model Context Protocol (MCP) 的開源專案，由 C# 開發，讓 Claude Desktop 和 Claude Code 能夠直接操作 Microsoft Office 文件。它在 2026 年 6 月登上 GitHub Trending #1（C# 分類），目前已有超過 3,200+ stars。

核心功能

  • Excel 自動化：讀取工作表、篩選資料、生成樞紐分析表、繪製圖表
  • Word 文件操作：插入段落、設定樣式、生成報表、匯出 PDF
  • PowerPoint 簡報製作：新增投影片、插入圖片、套用模板、批次修改
  • 跨文件整合：從 Excel 提取資料 → 生成 Word 報表 → 製作 PPT 簡報

💡 適用場景

  • 資料分析師：自動化數據清洗、生成分析報表、繪製視覺化圖表
  • 行銷人員：批次生成客戶報告、製作提案簡報、更新行銷數據儀表板
  • 專案經理：自動化週報生成、會議記錄整理、進度追蹤報表
  • 財務人員：快速處理發票、生成財務報表、製作預算簡報

為什麼選擇 OfficeCLI？

✅ OfficeCLI

  • 原生 Office 格式支援
  • Claude AI 自然語言操作
  • 無需學習 VBA 或 Office Scripts
  • 支援複雜邏輯與多文件處理

❌ 傳統 VBA/Office Scripts

  • 需要程式設計經驗
  • 語法複雜，學習曲線陡峭
  • 除錯困難，維護成本高
  • 跨應用整合需額外開發

環境需求與前置準備

系統需求

  • 作業系統：Windows 10/11（需安裝 Microsoft Office 2016 或更新版本）
  • Claude Desktop：1.0.0 或更新版本（支援 MCP）
  • .NET Runtime：.NET 8.0 或更新版本
  • Office 版本：Office 2016/2019/2021/Microsoft 365

⚠️ 注意事項

OfficeCLI 目前僅支援 Windows 系統，因為它依賴 Office COM Interop。Mac 使用者可使用 Microsoft Graph API 替代方案，或透過 Windows 虛擬機執行。

安裝 .NET Runtime

# 下載 .NET 8.0 SDK（包含 Runtime）
# 前往：https://dotnet.microsoft.com/download/dotnet/8.0

# 驗證安裝
dotnet --version
# 輸出範例：8.0.201

OfficeCLI 安裝教學

步驟 1：下載 OfficeCLI

# 方法一：從 GitHub Releases 下載最新版本
# 前往：https://github.com/microsoft/OfficeCLI/releases
# 下載 OfficeCLI-win-x64.zip 並解壓縮到 C:\Tools\OfficeCLI

# 方法二：使用 Git 克隆（需要自行編譯）
git clone https://github.com/microsoft/OfficeCLI.git
cd OfficeCLI
dotnet build -c Release

步驟 2：設定 Claude Desktop MCP

編輯 Claude Desktop 的 MCP 設定檔（位於 %APPDATA%\Claude\claude_desktop_config.json）：

{
  "mcpServers": {
    "officecli": {
      "command": "C:\\Tools\\OfficeCLI\\OfficeCLI.exe",
      "args": ["--mcp"],
      "env": {
        "OFFICE_AUTOMATION_MODE": "true"
      }
    }
  }
}

步驟 3：重啟 Claude Desktop

關閉並重新開啟 Claude Desktop，在聊天介面中應該會看到「OfficeCLI」出現在可用工具列表中。

✅ 驗證安裝

在 Claude Desktop 中輸入：

請列出目前可用的 MCP 工具

如果看到 officecli_read_excel、officecli_create_word 等工具，代表安裝成功。

最佳實踐與效能優化

提高成功率的技巧

  • 明確指定檔案路徑：使用絕對路徑（如 C:\Data\file.xlsx）避免找不到檔案
  • 分段執行複雜任務：將大型任務拆解為多個步驟，每步驟確認後再繼續
  • 提供範例格式：告訴 Claude 預期的輸出格式（如「表格需包含標題列」）
  • 備份原始檔案：在修改前先複製一份，避免誤操作

效能優化建議

  • 關閉 Office 視窗：OfficeCLI 在背景執行，開啟 Office 視窗會降低速度
  • 減少讀寫次數：一次性讀取資料到記憶體，批次處理後再寫入
  • 使用範圍選取：指定工作表範圍（如 A1:E100）而非讀取整份檔案

常見問題與解決方案

問題 1：Claude 無法找到 OfficeCLI 工具

解決方案：

  1. 確認 claude_desktop_config.json 中的路徑正確
  2. 檢查 OfficeCLI.exe 是否有執行權限
  3. 重啟 Claude Desktop 並清除快取

問題 2：執行時出現「COM 物件建立失敗」錯誤

解決方案：

  • 確認已安裝 Microsoft Office（不支援 Office Online）
  • 檢查 Office 版本是否為 2016 或更新
  • 以「系統管理員身分」執行 Claude Desktop

問題 3：處理大型 Excel 檔案時速度緩慢

解決方案：

  • 使用範圍選取限制讀取資料量
  • 關閉 Excel 中的自動計算功能
  • 考慮將資料分批處理
