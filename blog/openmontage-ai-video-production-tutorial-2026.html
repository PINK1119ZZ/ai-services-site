核心發現：OpenMontage（calesthio/OpenMontage，GitHub 52K★）是目前最完整的開源 AI 視頻生產系統，整合 12 個 production pipeline、100+ 工具、700+ agent skill files，支援 WAN 2.1、Hunyuan Video、CogVideo 等主流視頻模型。在 Claude Code 環境中運行，60 秒視頻約 10-20 分鐘生成。AGPL 授權，產出內容用戶擁有完整版權。台灣繁中深度評測幾乎空白，本文提供完整架構解析與環境設定教學。

為什麼 AI 視頻生產還沒有普及？

如果你用過 Sora、Runway Gen-3 或 Kling，你大概有同樣的挫折：生成一段好看的視頻，需要的不只是一個模型，而是一條完整的工作流。

典型的 AI 視頻生產流程長這樣：

  1. 用 LLM 生成腳本和分鏡
  2. 用圖像模型生成分鏡圖
  3. 用視頻模型把分鏡圖轉成視頻片段
  4. 用音樂生成或 TTS 加上配音配樂
  5. 用剪輯工具拼接所有片段
  6. 加字幕、特效、色彩調整

手動做一次這個流程需要 2-4 小時，而且每個環節都是不同工具、不同格式、不同 API。OpenMontage 把這 6 個步驟打包成一個可以在 Claude Code 裡執行的自動化 Agent 系統。

OpenMontage 是什麼？

OpenMontage 是由 calesthio 主導開發的開源 AI 視頻生產框架。它的定位不是另一個「AI 影片生成工具」，而是一個完整的 AI 視頻生產 OS（Operating System）——把所有視頻生產環節的 AI 工具整合進一個統一的 Agent 系統，讓非技術用戶也能透過自然語言指令生產高品質視頻。

截至 2026 年 10 月，GitHub 上 calesthio/OpenMontage 有 52,000+ stars，在 2026 Week 26 獲選「全語言 #1 Repo of the Week」，是今年開源社群關注度最高的 AI 創作工具。

OpenMontage 的授權說明

OpenMontage 使用 AGPL 授權。對於個人和非商業用途，完全免費。重要的是：用 OpenMontage 生成的視頻內容，版權歸用戶所有——AGPL 的限制在於系統本身的修改必須回饋社群，不影響產出內容的所有權。

架構解析：12 個 Pipeline，100+ 工具

Pipeline 系統

OpenMontage 的核心是 12 個預建的 production pipeline，每個都是針對特定視頻類型優化的完整工作流：

Pipeline 用途 預估生成時間
short-reel 15-60 秒短影音（IG / TikTok） 10-20 分鐘
explainer 產品或概念說明視頻（2-5 分鐘） 30-60 分鐘
documentary 紀錄片風格長視頻（10-30 分鐘） 2-4 小時
ad-spot 廣告片段（15-30 秒） 8-15 分鐘
news-brief 新聞摘要視頻（輸入文章 → 視頻） 15-25 分鐘
podcast-clips Podcast 切片 + 字幕視頻 5-10 分鐘/片
slide-narrator 簡報轉旁白視頻 20-40 分鐘
avatar-talking 虛擬人物說話視頻 10-20 分鐘
music-video 音樂視頻（輸入歌詞 → MV） 30-60 分鐘
product-showcase 產品展示視頻（輸入圖片 + 說明） 15-25 分鐘
educational 教育課程視頻 45-90 分鐘
custom 自定義 pipeline（YAML 設定） 視設定而定

工具層（100+ Tools）

每個 pipeline 背後是 OpenMontage 內建的 100+ 工具，按功能分類：

  • 視頻生成模型：WAN 2.1、Hunyuan Video、CogVideoX、AnimateDiff、Pika Labs API
  • 圖像生成：SDXL、Flux、DALL-E 3、Ideogram
  • 語音合成（TTS）：Piper TTS（本地）、ElevenLabs API、OpenAI TTS
  • 音樂生成：AudioCraft、Suno API
  • 剪輯工具：FFmpeg 封裝、MoviePy、自動字幕生成
  • 腳本生成：GPT-6.1 Sol、Claude Opus 4（via Claude Code）
  • 資產管理：本地緩存、雲端儲存整合（S3 / GCS）

Agent Skill Files（700+）

OpenMontage 最獨特的設計是 700+ 個 Agent Skill Files。這些是預先訓練好的指令集，告訴 Agent 如何在特定情況下使用特定工具組合。例如：

  • cinematic-transition.skill：如何在兩個場景之間加入電影級的轉場效果
  • talking-head-lip-sync.skill：如何把語音和虛擬人物嘴型對齊
  • b-roll-selector.skill：如何根據腳本語意自動選擇合適的 B 卷素材

這些 Skill Files 可以疊加使用，也可以自定義。700+ 個 skills 相當於 700 個「業界最佳實踐」的視頻製作技巧，被系統化地教給 Agent。

硬體需求分析

OpenMontage 是計算密集型的系統，不同 pipeline 的硬體需求差異很大：

使用場景 最低配置 建議配置
文字 + TTS（無視頻生成） CPU only，4GB RAM 8 core CPU，16GB RAM
短視頻（<60 秒） NVIDIA RTX 3090（24GB VRAM） A100 40GB 或 H100
長視頻（1-10 分鐘） A100 40GB H100 80GB 或雙卡設定
WAN 2.1（全品質） 80GB VRAM（A100/H100） H100 x2 NVLink

重要說明：如果你只是想測試 OpenMontage 的腳本生成和 pipeline 邏輯（不跑本地視頻模型），可以用 API 模式——系統會把視頻生成步驟外包給 Runway、Kling 或 Pika 的 API，本機只需要 CPU 環境。本文後半段會說明這個模式。

安裝教學

前置需求

  • Claude Code（已安裝，用 Claude Max 訂閱）
  • Python 3.11+
  • Git
  • ffmpeg（brew install ffmpeg 或 apt install ffmpeg）
  • CUDA 12.2+（如果要跑本地視頻模型）

步驟一：Clone OpenMontage

git clone https://github.com/calesthio/OpenMontage.git
cd OpenMontage
pip install -e ".[all]"

[all] 會安裝所有可選依賴，包含本地視頻模型支援。如果只要 API 模式，用 pip install -e ".[api]"。

步驟二：設定環境變數

# .env 檔案（在 OpenMontage 根目錄建立）
ANTHROPIC_API_KEY=your_claude_api_key
OPENAI_API_KEY=your_openai_key        # 可選，用於 DALL-E
ELEVENLABS_API_KEY=your_el_key        # 可選，用於高品質語音
RUNWAY_API_KEY=your_runway_key        # 可選，API 模式視頻生成

# 如果要用 DigitalOcean Spaces 儲存輸出
DO_SPACES_KEY=your_spaces_key
DO_SPACES_SECRET=your_spaces_secret
DO_SPACES_BUCKET=your_bucket_name

步驟三：在 Claude Code 安裝 MCP Server

# 在 OpenMontage 目錄下執行
python -m openmontage.mcp install

# 這會自動把 OpenMontage 的 MCP server 加到 Claude Code 設定
# 等同於手動在 ~/.config/claude/mcp.json 加入：
# {
#   "servers": {
#     "openmontage": {
#       "command": "python",
#       "args": ["-m", "openmontage.mcp.server"],
#       "cwd": "/path/to/OpenMontage"
#     }
#   }
# }

步驟四：驗證安裝

python -m openmontage check

# 正常輸出：
# ✅ Claude Code MCP: connected
# ✅ FFmpeg: v6.1.1
# ✅ Python 3.11.9
# ✅ CUDA: 12.2 (if GPU available)
# ⚠️  WAN 2.1: not loaded (set LOAD_WAN=true to enable)
# ⚠️  Hunyuan: not loaded (set LOAD_HUNYUAN=true to enable)

第一個視頻：用 Claude Code 生成

安裝完成後，打開 Claude Code，試試這個指令：

用 OpenMontage 的 short-reel pipeline，
製作一個 30 秒的「AI 工具選擇指南」短影音，
配上中文旁白，使用 Piper TTS，
輸出 1080x1920 垂直格式（IG Reel）

Claude Code 會：
1. 自動選擇 short-reel pipeline
2. 用 GPT-6.1 Sol / Claude Opus 4 生成腳本和分鏡
3. 用 Flux 生成各分鏡的背景圖
4. 用 WAN 2.1（本地）或 Runway（API）生成視頻
5. 用 Piper TTS 合成中文旁白
6. 用 FFmpeg 拼接所有片段，加字幕
7. 輸出 output/short-reel-[timestamp].mp4

API 模式（沒有 GPU 的情況）

如果你沒有高端 GPU，可以用 API 模式讓視頻生成步驟走外部 API：

# 設定 API 模式，視頻生成外包給 Runway Gen-4
export OPENMONTAGE_VIDEO_BACKEND=runway

# 或使用 Kling（通常比 Runway 便宜）
export OPENMONTAGE_VIDEO_BACKEND=kling

# 圖像生成用 DALL-E 3（不需要本地 GPU）
export OPENMONTAGE_IMAGE_BACKEND=dalle3

API 模式的優缺點：

  • ✅ 不需要 GPU，MacBook Air 也能用
  • ✅ 啟動速度快（不需要載入模型）
  • ❌ 視頻生成費用（Runway Gen-4 約 $0.05/秒，一支 60 秒視頻約 $3-5）
  • ❌ 依賴外部 API 穩定性和速度

WAN 2.1 深度整合

WAN（Wide Area Network）2.1 是 OpenMontage 整合的最高品質視頻模型，由 Wan AI 開源。它的特點：

  • 時序一致性極強：物件在不同幀之間的動作流暢，沒有傳統 AI 視頻的「閃爍」問題
  • 物理理解能力：重力、光影、流體動作表現接近真實
  • 長視頻支援：可生成最長 120 秒的單段視頻（需要 80GB VRAM）
  • Multi-modal 輸入：支援文字轉視頻（T2V）、圖片轉視頻（I2V）、視頻轉視頻（V2V）

在 OpenMontage 中啟用 WAN 2.1：

# 下載模型（約 80GB，需要穩定網路）
python -m openmontage.models download wan2.1

# 啟用時設定
export LOAD_WAN=true
export WAN_PRECISION=bf16  # 或 fp16 節省顯存
python -m openmontage.server

OpenMontage 的實際應用場景

1. 內容創作者：每日短影音自動化

最適合 OpenMontage 的使用者是：每天需要發布 IG Reel、YouTube Shorts 或 TikTok，但自己剪片費時費力的內容創作者。

一個典型的自動化流程：

  1. 每天早上從 RSS / 爬蟲抓取 3 個 AI 新聞
  2. 讓 OpenMontage 的 news-brief pipeline 自動生成 3 支 60 秒短影音
  3. 自動上傳到 YouTube Shorts 和 IG Reel（透過 API）

全流程自動化的情況下，人工只需要設定一次 + 偶爾審核輸出品質。

2. 行銷團隊：產品宣傳視頻

product-showcase pipeline 特別適合電商或 SaaS 產品。輸入：產品圖片 + 功能說明文字，輸出：30 秒產品展示視頻，有旁白、有字幕、有背景音樂。不需要請視頻製作公司，預算省 80%+。

3. 教育機構：課程影片量產

educational pipeline 可以把已有的課程 PDF 或 Notion 文檔自動轉換成有旁白的教學視頻，適合線上課程平台或企業內訓。

4. 新聞媒體：自動化圖文轉視頻

news-brief pipeline 讓新聞機構可以把每篇文字新聞自動轉成 60-90 秒的視頻摘要，擴大視頻內容覆蓋率，不需要增加視頻製作人員。

自定義 Pipeline（進階）

OpenMontage 的 custom pipeline 允許你用 YAML 定義自己的視頻生產流程：

# my-pipeline.yaml
name: "tw-tech-reel"
description: "台灣科技新聞 IG Reel"
output:
  resolution: "1080x1920"
  fps: 30
  duration: 45

steps:
  - id: script
    tool: llm
    model: claude-opus-4
    prompt: |
      根據以下新聞，寫一個 45 秒的 IG Reel 腳本，
      繁體中文，口語化，每句不超過 15 字：
      {{input.news_text}}

  - id: voiceover
    tool: piper_tts
    text: "{{steps.script.output}}"
    voice: "zh-TW-female-1"

  - id: visuals
    tool: flux
    prompts: "{{steps.script.scene_prompts}}"
    style: "modern tech, clean design"

  - id: video_segments
    tool: wan2.1
    images: "{{steps.visuals.output}}"
    motion_preset: "subtle"

  - id: assemble
    tool: ffmpeg
    segments: "{{steps.video_segments.output}}"
    audio: "{{steps.voiceover.output}}"
    subtitles: auto

限制與注意事項

  • 算力需求高：本地跑 WAN 2.1 需要 80GB VRAM，個人消費級硬體難以負擔。API 模式可以繞過，但有費用
  • AGPL 授權限制：如果你修改了 OpenMontage 的程式碼並用於商業服務，需要開放修改後的程式碼。產出視頻內容不受此限制
  • 生成時間：即使是最快的 short-reel pipeline，也需要 10-20 分鐘。不適合需要即時預覽的場景
  • 品質一致性：自動化生成的視頻品質比人工剪輯有差距，適合量產，不適合需要精緻品質的旗艦宣傳片
