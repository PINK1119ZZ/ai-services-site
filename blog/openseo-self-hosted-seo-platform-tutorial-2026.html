OpenSEO 是什麼？為什麼它讓 6,000 個開發者放棄 Ahrefs？

Cloudflare Workers 自架教學（20 分鐘完成）

以下是完整部署流程，不需要付費伺服器，Cloudflare Workers 免費方案即可。

步驟 1：Fork 並安裝依賴

# Fork GitHub repo 後 clone 到本地
git clone https://github.com/every-app/open-seo.git
cd open-seo

# 安裝依賴（Node.js 18+ 必須）
npm install

# 安裝 Wrangler CLI（Cloudflare Workers 工具）
npm install -g wrangler
wrangler login

步驟 2：設定環境變數

建立 .env.local 並填入以下設定：

# Google Search Console（必填，取得真實排名數據）
GOOGLE_SITE_VERIFICATION=your_gsc_token
GOOGLE_OAUTH_CLIENT_ID=your_oauth_client_id
GOOGLE_OAUTH_CLIENT_SECRET=your_oauth_client_secret

# DataForSEO API（選填，提升關鍵字數據品質）
# 免費方案每天 1,000 次查詢
DATAFORSEO_EMAIL=your_email
DATAFORSEO_PASSWORD=your_api_password

# Cloudflare R2（選填，儲存爬蟲快取數據）
R2_BUCKET_NAME=openseo-cache
R2_ACCOUNT_ID=your_cloudflare_account_id

步驟 3：設定 wrangler.toml

name = "openseo"
main = "src/index.ts"
compatibility_date = "2026-09-01"

[vars]
ENVIRONMENT = "production"

[[d1_databases]]
binding = "DB"
database_name = "openseo-db"
database_id = "your-d1-database-id"

[[r2_buckets]]
binding = "CACHE"
bucket_name = "openseo-cache"

步驟 4：建立 D1 資料庫並初始化

# 建立 Cloudflare D1 資料庫（免費）
wrangler d1 create openseo-db

# 記下輸出的 database_id，填回 wrangler.toml

# 初始化 schema
wrangler d1 execute openseo-db --file=./schema.sql

步驟 5：本地測試

# 本地開發測試
npm run dev

# 瀏覽器開啟 http://localhost:8787
# 你應該能看到 OpenSEO 的控制面板

步驟 6：部署到 Cloudflare Workers

# 部署（一鍵完成）
npm run deploy

# 輸出類似：
# Published openseo (1.23 sec)
# https://openseo.your-username.workers.dev

恭喜！你的 OpenSEO 實例已經運行在 Cloudflare Workers 上，全球 CDN 加速，完全免費。

連接 Google Search Console：取得真實排名數據

這是 OpenSEO 最強的功能之一——直接整合你的 GSC 真實數據，而非 Ahrefs/Semrush 的估算值。

1. 建立 Google OAuth 2.0 憑證

  1. 前往 Google Cloud Console
  2. 建立新專案，啟用 Google Search Console API
  3. OAuth 2.0 用戶端 ID → 選擇「Web 應用程式」
  4. 授權重新導向 URI 加入：https://openseo.your-username.workers.dev/auth/callback
  5. 下載 JSON 憑證，提取 client_id 和 client_secret

2. 授權你的 GSC 網站

# 透過 CLI 完成授權流程
wrangler secret put GOOGLE_OAUTH_CLIENT_ID
# 輸入你的 client_id

wrangler secret put GOOGLE_OAUTH_CLIENT_SECRET
# 輸入你的 client_secret

# 重新部署以生效
npm run deploy

完成後，在 OpenSEO 控制面板登入 Google 帳號，授權存取你的 Search Console 屬性。你將立刻能看到：

  • 每個頁面的真實點擊次數、曝光次數、CTR、平均排名
  • 哪些關鍵字在第 2 頁（位置 11-20）——這些是最快能優化到第 1 頁的機會
  • 索引覆蓋率問題（哪些頁面沒被 Google 收錄）

MCP Server 設定：讓 Claude 直接查 SEO 數據

這是 OpenSEO 最讓開發者興奮的功能：MCP（Model Context Protocol）Server 支援，讓你可以直接在 Claude Desktop、Codex、Cursor 等 AI 工具中查詢 SEO 數據。

啟用 MCP Server

# OpenSEO 已內建 MCP Server，只需在部署時啟用
# 在 wrangler.toml 加入：

[vars]
ENABLE_MCP_SERVER = "true"
MCP_AUTH_TOKEN = "your-secure-random-token"

在 Claude Desktop 設定 OpenSEO MCP

// ~/.claude/claude_desktop_config.json
{
  "mcpServers": {
    "openseo": {
      "command": "npx",
      "args": ["mcp-remote", "https://openseo.your-username.workers.dev/mcp"],
      "env": {
        "MCP_AUTH_TOKEN": "your-secure-random-token"
      }
    }
  }
}

OpenSEO 進階功能：競品分析與自動化報告

競品關鍵字分析

OpenSEO 的競品分析功能整合 Common Crawl 的公開網頁爬蟲索引，可以估算任意網域的關鍵字排名：

# 使用 OpenSEO CLI 分析競品
npx openseo-cli analyze-competitor \
  --domain competitor.com \
  --compare-with yourdomain.com \
  --export competitor-gap-report.json

輸出包含：

  • 競品有排名但你沒有的關鍵字（Content Gap）
  • 你排名比競品高的關鍵字（優勢鞏固）
  • 雙方都排名但你位置較低的關鍵字（優先優化目標）

自動化 SEO 週報

配合 Cloudflare Workers Cron Trigger，可以設定自動生成週報並發送到 Telegram 或 Slack：

# wrangler.toml 加入 Cron Trigger
[triggers]
crons = ["0 9 * * 1"]  # 每週一早上 9 點（UTC）

// src/cron.ts
export async function handleCron(env: Env) {
  const report = await generateWeeklySeoReport(env);
  
  // 發送到 Telegram
  await fetch(`https://api.telegram.org/bot${env.TELEGRAM_BOT_TOKEN}/sendMessage`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      chat_id: env.TELEGRAM_CHAT_ID,
      text: formatReportAsMarkdown(report),
      parse_mode: 'Markdown'
    })
  });
}

這樣每週一你就會收到自動生成的 SEO 報告，完全不需要手動登入任何工具。

OpenSEO 的限制：什麼情況下還是需要 Ahrefs？

誠實說，OpenSEO 不是在每個場景都能完全取代商業工具：

場景 OpenSEO 建議
個人部落格 / 中小型網站 ✅ 完全夠用 直接用 OpenSEO，省 $130-260/月
電商網站（<1,000 頁） ✅ 搭配 GSC 整合很強 OpenSEO + GSC 即可
SEO 代理商（大量客戶） ⚠️ 需要自架多實例 可用，但管理成本較高
大型媒體（10 萬+ 頁） ⚠️ Common Crawl 覆蓋率不足 Ahrefs Enterprise 仍有優勢
精準反向連結數據 ⚠️ Common Crawl 有延遲 Ahrefs 的即時爬蟲更準

結論：如果你是獨立開發者、部落客、中小企業，OpenSEO 完全可以取代 Ahrefs/Semrush，立刻省下每月 $130-260。如果你需要即時反向連結監控或管理 100 個以上客戶網站，商業工具仍有其價值。

台灣開發者常見問題

Q：OpenSEO 的關鍵字數據支援中文嗎？

支援。Common Crawl 包含繁體中文和簡體中文的網頁索引，Google Search Console 整合後的數據完全支援中文關鍵字。不過對於台灣在地長尾關鍵字，GSC 整合的真實數據比估算值更準確。

Q：Cloudflare Workers 免費方案夠用嗎？

對於月流量 1K-10K 的網站完全夠用。免費方案每天 100K 次請求，D1 資料庫 5GB，R2 儲存 10GB。超過這個量建議升級 Cloudflare Workers Paid（$5/月），比 Ahrefs 便宜 96%。

Q：自架數據安全嗎？

比商業工具更安全。你的 SEO 數據、競品分析查詢都儲存在你自己的 Cloudflare D1，不會上傳到任何第三方伺服器。Ahrefs 和 Semrush 的 Terms of Service 明確表示他們會記錄你的查詢用於改善產品。

Q：DataForSEO 整合是免費的嗎？

DataForSEO 有免費方案（每天 1,000 次查詢），用於補充 OpenSEO 的關鍵字搜尋量數據。大多數個人網站在免費方案內即可。
