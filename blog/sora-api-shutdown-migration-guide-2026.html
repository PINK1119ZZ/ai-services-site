建立相容層（Adapter Pattern）

建議不要直接改所有呼叫點，而是建立一個抽象層，讓未來切換更容易：

# video_provider.py — 統一介面
import os
import requests
import time

class VideoProvider:
    def __init__(self, provider="higgsfield"):
        self.provider = provider
        if provider == "higgsfield":
            self.api_key = os.getenv("HIGGSFIELD_API_KEY")
            self.base_url = "https://api.higgsfield.ai/v1"
    
    def generate_video(self, prompt: str, duration: int = 5, 
                       resolution: str = "1080p") -> str:
        """生成影片，返回影片 URL"""
        if self.provider == "higgsfield":
            return self._higgsfield_generate(prompt, duration, resolution)
        raise ValueError(f"未知的 provider: {self.provider}")
    
    def _higgsfield_generate(self, prompt, duration, resolution):
        # 建立任務
        resp = requests.post(
            f"{self.base_url}/generations",
            headers={"Authorization": f"Bearer {self.api_key}"},
            json={
                "model": "higgsfield-video-v1",
                "prompt": prompt,
                "duration": duration,
                "resolution": resolution,
                "aspect_ratio": "16:9"
            }
        )
        resp.raise_for_status()
        job_id = resp.json()["id"]
        
        # 輪詢直到完成
        for _ in range(60):  # 最多等 5 分鐘
            time.sleep(5)
            check = requests.get(
                f"{self.base_url}/generations/{job_id}",
                headers={"Authorization": f"Bearer {self.api_key}"}
            ).json()
            
            if check["status"] == "completed":
                return check["output"]["url"]
            elif check["status"] == "failed":
                raise Exception(f"影片生成失敗: {check.get('error')}")
        
        raise TimeoutError("影片生成超時")

# 使用範例
provider = VideoProvider(provider="higgsfield")
video_url = provider.generate_video(
    prompt="台灣夜市熱鬧場景，霓虹燈光，電影風格",
    duration=10,
    resolution="1080p"
)
print(f"影片 URL: {video_url}")

七、FAQ：最常問的 5 個問題

Q1：我的 Sora 生成的影片資料會被刪除嗎？
A：只有消費者應用（app.sora.com）的影片已於 2026-05-26 刪除。透過 API 生成的影片是儲存在你自己的 storage（你呼叫時指定的儲存位置），OpenAI 不保留這些檔案的副本。
Q2：Sora API Key 可以繼續用在其他 OpenAI 服務嗎？
A：Sora API 有專屬的存取申請流程。如果你只申請了 Sora 存取，其他 OpenAI API（GPT-5.4、Whisper 等）需要另行申請。一般的 OpenAI API Key 則不受影響。
Q3：OpenAI 以後還會出影片 API 嗎？
A：目前 OpenAI 沒有公開宣布替代的影片 API 計畫。Sora 的商業模式調整說明影片生成是燒錢的業務，短期內 OpenAI 專注在語言和推理模型。建議不要再等 OpenAI 的方案。
Q4：遷移到哪個方案影片品質最接近 Sora？
A：主觀上，Google Veo 3.1（Vertex AI）在物理一致性方面最接近 Sora，但需要申請白名單。其次是 Kling 3.0 和 Seedance 2.0。Higgsfield 則是在模型選擇彈性上最強。
Q5：我能在 9/24 之前測試新方案嗎？
A：完全可以，而且強烈建議。所有提到的替代方案（Higgsfield、Kling、Seedance）目前都有 API 可以立即申請使用。建議今天就申請 key，週末完成測試，下週初上線。
