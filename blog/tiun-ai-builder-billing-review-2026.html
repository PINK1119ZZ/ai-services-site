這是大多數 AI 創業者遇到的第二道牆。第一道牆（開發）被 AI 工具打破了，但第二道牆（商業化基礎設施）還是一樣碎片化：你需要 Clerk 管帳號、Stripe 收錢、另一個工具計算使用量、再一個工具開發票……每個月光這些 SaaS 工具本身就要幾百美元，還得自己維護 webhook 同步。

tiun. 想解決的正是這個問題。

🔍 tiun. 是什麼？

tiun.（官網：tiun.io）是一個面向 AI 與 SaaS 創業者的 統一商業後端（Unified Commercial Backend）。一個 SDK 安裝後，你就擁有了：

  • Authentication：用戶登入、Magic Link、OAuth、Session 管理
  • Payments：收一次性款項，全球支付，支援信用卡、Apple Pay、Google Pay
  • Billing：訂閱制、時間計費、使用量計費（按 token / API 呼叫 / 時間）
  • Invoicing & Tax：自動開發票、MoR 全球稅務處理（VAT、GST、消費稅）
  • Customer Data & Analytics：客戶管理、收入分析、使用量視覺化

這個組合，原本你需要 Clerk（$0-800/月，依 MAU 計費）+ Stripe（2.9%+$0.30/次）+ Orb 或 Metronome（$1,000/月起）+ 稅務工具。tiun. 把所有東西放進一個系統，費率約 3.4% + $0.30，就包含 MoR 服務。

💡 什麼是 MoR（Merchant of Record）？

MoR 指的是在法律上承擔銷售責任的實體。使用 tiun. 的 MoR 功能，tiun. 會代替你處理全球各地的稅務申報（歐盟 VAT、澳洲 GST、台灣電子發票等），你不需要自己在每個國家設稅務帳號。這對剛起步的 AI 創業者來說省了大量合規成本。

😓 AI 創業者的商業化痛點

在深入 tiun. 功能前，先看看這些工具試圖解決的真實問題：

❌ 碎片化整合的噩夢Stripe webhook → 觸發 Clerk 用戶更新 → 同步到自己的 DB → 更新 Orb 使用量 → 每個環節都可能 fail，debug 要花幾天。
❌ 使用量計費的複雜度按 token / API call 收費，需要 metering 系統、rate limiting、餘額管理。這一塊光靠 Stripe 做不到，要另外買 Orb（$1,000/月起）或 Metronome（剛被 Stripe 收購）。
❌ 全球稅務的坑在歐盟賣數位產品，每個國家的 VAT 不一樣。在澳洲賣超過 AUD 75,000 要繳 GST。自己處理這些很容易踩坑。
❌ 工具費用疊加Clerk 免費版最多 10K MAU，超過 $0.02/MAU。50K MAU = $800/月。加上 Stripe 2.9%、Orb $1,000/月、稅務工具 $200/月，啟動期就要幾千美元月費。

⚙️ tiun. 核心功能拆解

1. Auth：從 Magic Link 到 OAuth，一行程式碼搞定

tiun. 的 Auth 模組支援 Email + Password、Magic Link、Google/GitHub OAuth，以及標準 Session 管理。與 Clerk 的差異在於：Clerk 的定價按 MAU 計費，用戶多了費用會爆。tiun. 把 Auth 整合進同一個系統定價，不單獨計費 MAU。

# 安裝 tiun SDK（Node.js 示例）
npm install @tiun/sdk

# 初始化
import { Tiun } from '@tiun/sdk';
const tiun = new Tiun({ apiKey: process.env.TIUN_API_KEY });

# 用戶登入 / 建立
const user = await tiun.auth.signUp({
  email: 'user@example.com',
  password: 'securePassword123'
});

# 驗證 Session
const session = await tiun.auth.verifySession(token);

2. 訂閱計費：月費 SaaS 最快的啟動方式

定義定價方案、建立訂閱、自動更新扣款，tiun. 的訂閱模組處理整個生命週期（試用期 → 啟用 → 升降級 → 取消 → 退款）。你在 Dashboard 拉好定價方案，SDK 裡一行呼叫就能讓用戶訂閱。

# 建立訂閱
const subscription = await tiun.billing.createSubscription({
  customerId: user.id,
  planId: 'pro-monthly',  // 在 Dashboard 設定的方案 ID
  trialDays: 14           // 試用期（可選）
});

# 查詢訂閱狀態
const status = await tiun.billing.getSubscription(user.id);

3. 使用量計費（Usage-Based Billing）：AI 產品必備

這是 tiun. 最核心的差異化功能。對於 AI 產品（按 token 收費、按 API call 計費、按使用分鐘計費），tiun. 的 usage-based billing 是直接建在 SDK 裡的，不需要另外買 metering 工具：

# 記錄使用量（例：AI token 消耗）
await tiun.billing.recordUsage({
  customerId: user.id,
  metric: 'ai_tokens',     // 自訂指標名稱
  quantity: 1500,           // 本次消耗的 token 數
  timestamp: new Date()
});

# 設定計費方式（在 Dashboard 設定，或用 API）
# - 按量計費：$0.001 / 1000 tokens
# - 有上限的包月：每月 100K tokens，超出另計
# - 時間計費：$0.05 / 分鐘的 AI session

tiun. 稱之為「Time-Based Billing」，支援 Session 時間、Agent 運行時間、內容存取時間等多種計費維度，AI 產品幾乎所有常見的計費模式都能直接支援。

⚠️ tiun. vs Stripe 的重要說明

Stripe 是更強大的純支付平台，developer experience 無可比擬，生態系成熟。tiun. 的定位是「全合一後端」，不是要取代 Stripe，而是讓 早期 AI 創業者不需要自己拼湊多個工具。如果你的公司已經有專業的後端工程師，Stripe + 自家整合可能更靈活；如果你是個人開發者或小團隊，tiun. 能讓你更快上線。

🔧 快速上手：用 tiun. 在一天內啟動付費 AI 產品

1

建立 tiun. 帳號並取得 API Key

前往 tiun.io 免費註冊。完成後在 Dashboard → Settings → API Keys 取得你的 API Key。

2

安裝 SDK

一條指令搞定：

# Node.js
npm install @tiun/sdk

# Python
pip install tiun-sdk
3

在 Dashboard 設定定價方案

進入 Dashboard → Products → Create Plan。設定：

  • 方案名稱（例：Free / Pro / Enterprise）
  • 計費方式：訂閱制月費 or 使用量計費（指定 metric 名稱和費率）
  • 試用期（可選）
  • 功能限制（可選，整合 SDK 的 Feature Flag）
4

在程式碼中加入 Auth + Billing

以 Next.js + Python FastAPI AI 產品為例：

# 後端（Python FastAPI）
from tiun import Tiun
tiun = Tiun(api_key=os.environ['TIUN_API_KEY'])

@app.post('/api/ai/generate')
async def generate(request: Request):
    # 驗證用戶 session
    session = await tiun.auth.verify_session(request.headers.get('Authorization'))
    if not session:
        raise HTTPException(status_code=401)
    
    # 檢查用戶有無 Pro 方案
    subscription = await tiun.billing.get_subscription(session.user_id)
    if subscription.plan != 'pro':
        raise HTTPException(status_code=403, detail='需要 Pro 方案')
    
    # 執行 AI 任務
    result = await run_ai_task(request.body)
    
    # 記錄使用量
    await tiun.billing.record_usage(
        customer_id=session.user_id,
        metric='ai_tokens',
        quantity=result.tokens_used
    )
    
    return result
5

❓ tiun. 常見問題 FAQ

Q：tiun. 適合什麼階段的 AI 創業者？
最適合 早期到成長期的 AI 與 SaaS 創業者（0-$50K MRR）。在這個階段，整合成本和工具月費都是重要考量。tiun. 的一站式設計讓你把工程資源放在產品本身，而不是整合地獄。如果你的公司已有 50+ 人工程師和複雜的計費需求，純 Stripe + Orb 的客製化靈活度可能更適合。
Q：tiun. 的 Usage-Based Billing 可以怎麼計費？
tiun. 支援多種使用量計費模式：(1) 純量計費（每 1,000 tokens $0.01）；(2) 分層計費（用量越高單價越低）；(3) 包月上限 + 超量計費（$29/月包含 100K tokens，超出每千 $0.02）；(4) 時間計費（按 AI Session 的分鐘數計費）。你在 Dashboard 設定好邏輯，SDK 裡呼叫 record_usage() 就自動累計。
Q：我已經用 Stripe，值得換 tiun. 嗎？
如果你只有 Stripe 而沒有其他工具，換 tiun. 的誘因不大（Stripe 已很成熟）。但如果你還在另外付 Clerk / Auth0 管帳號，或是在考慮 Orb / Metronome 做 usage-based billing，那 tiun. 的全合一方案在早期確實更划算。建議先用 tiun. 的免費試用測試你的使用場景，再決定要不要遷移。
Q：tiun. 支援哪些支付方式？
透過 MoR 架構，tiun. 支援信用卡（Visa/Mastercard/Amex）、Apple Pay、Google Pay 等全球主流支付方式。台灣本地支付（LINE Pay、街口支付、iPass 等）目前尚未確認，建議在官網 FAQ 查詢最新支援狀況。
Q：tiun. 的稅務 MoR 包含台灣電子發票嗎？
tiun. 的 MoR 主要針對國際市場（歐盟 VAT、澳洲 GST、美國 Sales Tax）。台灣的電子發票（B2C GUI、B2B 統一發票）屬於台灣法規，建議直接詢問 tiun. 團隊確認，或另外使用台灣本地的電子發票服務（如 iCarry、玉山電子發票）做搭配。
Q：tiun. 有冤大頭費用（Price Lock-in）嗎？
目前 tiun. 採用交易費率制（~3.4% + $0.30），沒有固定月費（截至 Sep 2026）。這意味著早期零收入時不需要承擔固定成本，隨業務成長才按比例付費。但具體定價可能更新，建議直接查詢官網最新方案。
