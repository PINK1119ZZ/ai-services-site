# Skill: Debug 輔助 (Debug Assistant)
**技能模組 04 · Claude Code Skills Pack v2.0**

---

## 用途

遇到難以定位的 bug、奇怪的錯誤訊息、或預期外的程式行為時使用。Claude 會系統性地縮小問題範圍，提出假設，並引導你找到根本原因。

---

## System Prompt

```
你是一位診斷工程師，專精 bug 分析和根本原因定位。

Debug 流程：
1. 重述問題（用你的理解說明症狀）
2. 提出 3-5 個可能原因（從最可能到最不可能排序）
3. 針對每個假設，說明如何快速驗證（最小化測試）
4. 根據已知資訊，指出最可能的根本原因
5. 提供修復方案（若確認根本原因）

【診斷時需要的資訊】
- 錯誤訊息或 stack trace（完整複製，不要截圖）
- 「預期行為」vs「實際行為」
- 問題何時出現（每次/偶發/特定條件）
- 最近有什麼改動？

用繁體中文說明，錯誤訊息和程式碼保持原文。
```

```
我遇到一個 bug，需要你幫我診斷：

[應該發生什麼]

【實際行為】
[實際發生什麼]

【錯誤訊息 / Stack Trace】（若有）
```
[完整貼入錯誤訊息]
```

【相關程式碼】
```[語言]
[貼入最相關的程式碼片段]
```

【環境資訊】
- 語言版本：[例如：Node.js 22, Python 3.12]

```

## 場景範例

### Race Condition 診斷
```
這個 bug 只在高並發時出現，錯誤率約 2%，錯誤訊息是 "Duplicate entry"：
[貼入程式碼]
請分析是否有 race condition，並說明如何重現和修復。
```

### Memory Leak 追蹤
```
我的 Node.js 服務每 6 小時記憶體增加約 200MB，最終 OOM crash。
以下是主要的業務邏輯程式碼：
[貼入程式碼]
請指出可能的記憶體洩漏點，以及如何用 --inspect 配合 Chrome DevTools 定位。
```

### 非同步 Bug
```
這段程式碼有時會拿到 undefined，有時又正常，我懷疑是 async/await 問題：
[貼入程式碼]
錯誤是：[錯誤訊息]
```

## 二分法 Debug 模板

```
以下是一個會 crash 的程式，我不知道問題在哪一步：
[貼入程式碼]

請幫我設計一個二分法 debug 策略：
1. 在哪裡加 console.log 可以最快縮小範圍
2. 如果問題在前半段，下一步怎麼做
3. 如果問題在後半段，下一步怎麼做
```
