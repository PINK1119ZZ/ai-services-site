**核心資訊：**
- **發布日期：** 2026-08-07 Product Hunt #5（BrowserOS neo）
- **定位：** "The Missing Browser for Claude, Cowork & Codex"
- **GitHub：** github.com/browseros/browseros-neo（12K+ stars，open source）
- **官網：** browseros.com/neo（docs.browseros.com）
- **Y Combinator：** YC-backed（browseros.com footer 確認）
- **免費開源：** Free and open source（macOS + Windows）

**技術亮點：**
- 🔵 **Agent-friendly browser：** 專為 AI agents 設計的 Chromium fork
- 🔵 **One-click import：** 從 Chrome 一鍵匯入 logins，agents 用你的帳號
- 🔵 **MCP native：** Built-in MCP server，Claude Code/Cowork/Codex/Cursor/VS Code/Zed/GitHub Copilot 一鍵連接
- 🔵 **Watch live：** Cockpit view 顯示每個 agent、每個 site、每個 step
- 🔵 **Less tokens：** 交給 agent 簡化的 snapshot（非截圖），省 token 比 Claude Chrome extension 多
- 🔵 **Rewind anything：** 每個 agent session 存成可回放的 video，找錯誤、coach agent
- 🔵 **本機運行：** 不是 cloud browser，logins/sessions/screenshots/replays 全部本機檔案，不上傳

**與 Claude for Chrome 差異：**
- Claude for Chrome = Chrome extension，side panel，用你的 Chrome profile
- BrowserOS neo = 獨立瀏覽器，sits next to Chrome，agents 在 neo 瀏覽、你繼續用 Chrome

**變現角度：**
