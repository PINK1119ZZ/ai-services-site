## 🚀 如何使用

1. 開啟 Claude Code（claude.ai/code 或 claude CLI）
2. 找到對應場景的 `.md` 檔案
3. 複製 prompt 模板，替換 `[方括號]` 內的變數
4. 貼入 Claude Code 對話框，直接使用

---

## 💡 使用技巧

- 所有 prompt 都設計為**開箱即用**，修改 `[變數]` 後即可直接執行
- 建議配合 Claude Code 的「繼續」功能讓 AI 完成多步驟任務
- 對於複雜重構，先用 **架構分析 prompt** 再用 **重構執行 prompt**
