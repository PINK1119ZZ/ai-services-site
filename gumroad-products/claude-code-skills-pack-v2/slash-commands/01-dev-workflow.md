# Slash Commands 01 — 開發工作流（Dev Workflow）
> 10 個 Slash Commands，一鍵觸發常用開發操作
> 安裝：複製到 `.claude/commands/01-dev-workflow.md`
> 使用：在 Claude Code 輸入 `/` 後輸入指令名稱

## /review
**描述：** 快速程式碼審查（聚焦最重要的 3 個問題）

```
請對以下程式碼進行快速審查，聚焦最重要的 3 個問題：
- 安全性風險（Critical/High 優先）
- 明顯的效能問題
- 可能導致 Bug 的邏輯錯誤

每個問題用一段話說明，附上修復建議程式碼。
不需要列出風格問題或低優先级改善。

程式碼：
$SELECTION
```

## /explain
**描述：** 用簡單語言解釋這段程式碼的功能

```
用清晰、簡單的語言解釋這段程式碼：
1. 這段程式碼做什麼（一句話總結）
2. 關鍵步驟逐步說明（3-5 個步驟）
3. 潛在的邊界情況或注意事項
4. 如果有複雜邏輯，用類比說明

避免使用術語，讓非開發者也能理解主要功能。

程式碼：
$SELECTION
```
