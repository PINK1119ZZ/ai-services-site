❓ 常見問題

AI Agent 記憶工具是什麼？和直接用 context window 有什麼差別？▼
AI Agent 記憶工具負責把跨對話、跨 session 的重要資訊持久化儲存，讓下次 agent 啟動時可以快速讀取，而不是每次都把全部背景塞入 context window。這樣一來可以省下 34–61% 的 token 費用，二來可以突破 context 長度限制，讓 agent「記得」你幾週前做過什麼。
Contextberg 和 OpenClaw 怎麼整合？▼
Contextberg 在官方網站直接列出 OpenClaw 為原生支援平台。安裝 Contextberg 後，它會自動啟動本機 MCP server，OpenClaw 即可透過 MCP protocol 讀寫記憶。整合只需幾分鐘，無需 API key，資料完全留在本機。詳細教學請參考 完整評測文章。
這些工具的記憶資料安全嗎？▼
各工具的隱私保護方式不同：Contextberg 採本機儲存不上雲，隱私最高；scritty 使用 AES-256 端對端加密；LoreKit 自架時可自管資料；ContextPool 和 Valori 為雲端服務，採傳輸加密。如果你的工作涉及機密程式碼或客戶資料，建議優先選擇 Contextberg（本機）或 LoreKit（自架）。
AI Agent 記憶工具真的可以省 token 費用嗎？▼
是的。根據各工具官方和社群回報，使用記憶工具後，平均可省下 34–61% 的 input token 費用。省下比例取決於你的工作模式——長期持續性專案（如程式碼庫維護、文件撰寫）受益最大；短期一次性任務效果相對較小。以 Claude Sonnet 5 為例，每百萬 token $3，一天 100 次對話，每次平均 2,000 tokens，月節省可達 $36–73。
哪個工具對 Cursor / Windsurf / Kilo Code 用戶最友善？▼
scritty 和 ContextPool 透過雲端 MCP server 提供跨 IDE 支援，理論上可配合任何支援 MCP 的 coding agent（包括 Cursor、Windsurf、Kilo Code）。LoreKit 透過 REST API 也可整合。Contextberg 目前著重桌面 app + OpenClaw，但 macOS 用戶也可嘗試用 MCP 接入。
完全免費的選項有哪些？▼
LoreKit 自架版完全免費且無記憶數量限制（需要自架 Postgres）；scritty 和 LoreKit 的 hosted free tier 各提供 5,000 次免費記憶；Contextberg 有免費方案（Pro tier 待公告）；Valori 目前在 beta 期間免費。ContextPool 目前沒有免費 tier。
