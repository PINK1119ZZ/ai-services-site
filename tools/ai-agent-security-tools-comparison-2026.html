❓ 常見問題

NVIDIA OpenShell 是什麼？▾
NVIDIA OpenShell 是 NVIDIA 官方開源的 AI Agent 安全運行環境，提供 kernel-level policy enforcement、formal verification、credential injection 三層保護，讓 AI Agent 在企業環境中安全運作，特別適合需要 GPU workload 的場景。
VibeDefend 和 OpenShell 有什麼差異？▾
VibeDefend 專注於 vibe coding（AI 生成程式碼）的安全層，透過 npx 一行安裝在 coding agent 工作流程中插入安全掃描，防止 AI 生成惡意程式碼。OpenShell 則是 runtime 沙箱，保護 agent 執行時的系統資源存取。兩者定位不同，可搭配使用。
Hindsight 是 agent 安全工具嗎？▾
Hindsight 主要定位是 Agent Memory 系統（LongMemEval SOTA），但其安全面向在於防止 agent 因記憶不足導致重複決策錯誤、資料洩漏或越權操作。Fortune 500 企業用來確保 agent 操作可追蹤、可審計。
中小企業需要 AI Agent 安全工具嗎？▾
如果你的 AI Agent 會存取生產資料庫、客戶資料或執行系統指令，答案是肯定的。VibeDefend（npx 一行安裝）是最低成本的起點；若有 GPU 工作負載或企業合規需求，OpenShell 是更完整的選擇。
台灣企業使用 AI Agent 安全工具有什麼法規考量？▾
台灣個資法（PDPA）要求對個人資料的自動化處理有合理保護措施。AI Agent 若會處理客戶資料，部署 OpenShell 的 credential injection（避免 agent 直接接觸機密）或 Hindsight 的審計日誌，有助於符合個資法要求。
