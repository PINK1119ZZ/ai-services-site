❓ 常見問題

CodeRabbit 是什麼？和 GitHub Copilot 有什麼差？▼
CodeRabbit 是專為 PR Review 設計的 AI Bot，安裝後每個 PR 都會自動收到逐行評論、安全建議和架構改進，不需要開發者主動操作。GitHub Copilot 的 PR Review 功能（Copilot for PRs）只在 Enterprise $39/user 版本才有，且主要功能是 IDE 補全而非 PR Bot。如果你的核心需求是「每個 PR 自動被 AI 審查」，CodeRabbit 更直接。
小團隊（3–5 人）需要 AI Code Review 工具嗎？▼
非常需要。小團隊 code review 資源有限，往往互相 review 就草草帶過。AI 工具可在人工審查前自動標記 70–90% 的常見問題（命名規範、未處理的 edge case、潛在安全漏洞），讓人工 review 聚焦在更高層次的架構討論。從免費版開始：Qodo（PR-Agent OSS）+ Semgrep Community，零成本試跑 1 個月再評估。
如何在 DigitalOcean 架設 AI Code Review CI/CD？▼
DigitalOcean 有多種方案：(1) Droplet + GitHub Actions：最彈性，可安裝任何 self-hosted runner，搭配 SonarQube / Semgrep；(2) App Platform：直接 git push 觸發，適合小型專案；(3) Managed Kubernetes（DOKS）：企業規模，搭配 Snyk + CodeRabbit。DigitalOcean 提供 $200 免費點數，可以完整測試整套架構。
Cursor 和 Windsurf 哪個比較好？▼
兩者都是 AI-first IDE 的強力選手。Cursor（$20/月）生態更成熟、社群更大、模型選擇更多（Claude / GPT / Gemini）；Windsurf（$15/月）的 Cascade Agent 在多步驟任務上表現優秀，免費版更大方。建議：都有免費版，兩個都裝，用一週再決定。對多數開發者，Cursor 稍微領先；預算考量則選 Windsurf。
台灣企業使用 AI Code Review 有哪些合規考量？▼
主要有三點：(1) 程式碼外傳風險 — 若程式碼含商業邏輯或個資，傳送到外部 AI 服務有洩漏風險，建議使用 Tabnine Enterprise（本地）或 SonarQube 自架；(2) 個資法（PDPA） — AI Code Review 工具不應接觸含個資的測試資料，CI/CD 環境要做資料隔離；(3) 金融監管 — 金管會對雲端服務有境內落地要求，部分場景需選擇本地部署方案。
