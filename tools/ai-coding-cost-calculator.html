常見問題
Claude Code $100/月值得嗎？
Claude Code 針對 Agentic 任務（自動修 bug、重構、撰寫測試、MCP 整合）有明顯優勢，使用量高的開發者通常在 2-3 週內就能靠省下的時間回本。如果每天使用 2 小時以上，$100 月費通常是划算的。使用量較低（每天不到 1 小時）則 Cursor Pro $20 會是更好的 CP 值選擇。
Cursor 和 GitHub Copilot 有什麼不同？
Cursor 是完整的 IDE（基於 VS Code 分叉），強調多檔修改（Composer）和上下文理解；Copilot 是外掛式助手，可以裝在現有 IDE（VS Code、JetBrains 等），GitHub 整合更緊密，適合企業環境與 PR 流程自動化。習慣 JetBrains 的工程師通常選 Copilot；全新設定工作站的開發者通常選 Cursor。
AI coding 工具真的能提升 25% 生產力嗎？
McKinsey 2026 研究顯示，AI coding 工具對開發速度的平均提升約為 15-40%，中位數落在 25% 左右。但實際效果因任務類型差異很大：重複性高的任務（寫 CRUD、補測試、文件）提升幅度可達 40-60%；需要深度系統理解的任務（架構設計、複雜 debugging）提升幅度通常只有 10-20%。計算器預設值 25% 是保守中位數估算。
團隊應該統一用同一套工具，還是讓工程師自選？
5 人以下團隊讓工程師自選通常效率更高，因為每個人習慣不同。5 人以上建議統一工具，原因是：共享上下文、統一知識庫（MCP server）、方便企業計費管理。GitHub Copilot Business 和 Cursor Business 都有集中管理後台，適合 10 人以上團隊。
有沒有免費的 AI coding 工具可以先試用？
有幾個選項：OpenCode 完全免費（需自帶 API Key）、GitHub Copilot 有免費版（每月 2,000 次補全）、Cursor 有免費版（每月 50 次慢速請求）、Codeium 個人版免費（無使用量限制）。建議先用免費版感受工作流程，確認習慣後再考慮付費升級。
