🎯 HyperFrames 是什麼？

HyperFrames 是 HeyGen 在 2026 年 9 月推出的開源 HTML-to-Video 引擎（GitHub：HeyGen-Official/HyperFrames），核心理念是：用你熟悉的 HTML/CSS 語法描述影片結構，AI 自動生成含 Avatar 旁白的完整影片。

傳統 AI 影片製作需要開啟 HeyGen 介面、上傳腳本、手動排版。HyperFrames 把整個流程變成程式碼：你只需寫一份 HTML template，Claude Code 或任何支援 MCP 的 AI 就能直接呼叫 HyperFrames API 生成影片。

一句話定位：HyperFrames = 影片界的 React 元件。把影片拆成可複用的 HTML「幀」（Frame），讓 AI 自動組合成完整影片，適合大量生成產品介紹、教學影片、社群短片的開發者與行銷人。

🚀 5 步驟完整教學：用 Claude Code + HyperFrames 生成第一支 AI 影片

  • 步驟 1：取得 HeyGen API Key 前往 app.heygen.com → Settings → API，生成 API Key。HeyGen 免費帳號提供每月 1 分鐘影片額度，付費方案 Creator（$29/月）有 15 分鐘。
  • 步驟 2：Clone 並安裝 HyperFrames
# Clone HyperFrames 開源專案 git clone https://github.com/HeyGen-Official/HyperFrames.git cd HyperFrames # 安裝依賴（Node.js 18+ 需求） npm install # 設定環境變數 echo "HEYGEN_API_KEY=your_api_key_here" > .env
  • 步驟 3：設定 Claude Code MCP（選用，推薦） HyperFrames 提供 MCP Server 模式，讓 Claude 直接呼叫生成指令：
// ~/.claude/settings.json { "mcpServers": { "hyperframes": { "command": "node", "args": ["./HyperFrames/mcp-server.js"], "env": { "HEYGEN_API_KEY": "your_api_key_here" } } } }
  • 步驟 4：撰寫你的第一個 HyperFrame HTML 模板 HyperFrames 使用自定義 HTML 標籤描述影片結構：
<!-- product-intro.hframe.html — 產品介紹影片模板 --> <hyperframe duration="30"> <avatar id="tech_presenter_01" position="left" scale="0.8" /> <script type="speech" lang="zh-TW"> 大家好！今天要介紹的是我們全新的 AI 工具， 只需要三個步驟，就能讓你的工作效率提升 50%。 </script> <background color="#0f1117" /> <overlay type="title" text="🚀 AI 工具完整介紹" position="top-right" /> </hyperframe> <hyperframe duration="20"> <avatar id="tech_presenter_01" position="center" /> <script type="speech" lang="zh-TW"> 現在就掃描 QR Code，免費試用 14 天！ </script> <overlay type="cta" text="免費試用" url="https://example.com" /> </hyperframe>
  • 步驟 5：生成影片 — CLI 或 Claude 對話 兩種方式擇一：CLI 直接生成，或在 Claude 對話中直接下令。
# 方式 A：CLI 直接生成 npx hyperframes generate product-intro.hframe.html --output ./output/ # 方式 B：在 Claude Code 對話中（需設定 MCP） # 你：「幫我生成 product-intro.hframe.html 的影片，Avatar 用 tech_presenter_01，旁白語言繁中」 # Claude 自動呼叫 HyperFrames MCP → HeyGen API → 下載影片到 output/

❓ HyperFrames 常見問題（FAQ）

HyperFrames 完全免費嗎？

HyperFrames 本身是 MIT 開源免費。但生成影片需要呼叫 HeyGen API，HeyGen 的免費方案每月只有 1 分鐘影片額度，超過需付費（Creator $29/月起，才能使用 API）。簡言之：HyperFrames 工具免費，影片生成依 HeyGen 方案計費。

HyperFrames 跟 Claude Code 怎麼整合？

HyperFrames 提供 MCP Server 模式。設定 Claude Code 的 settings.json 加入 hyperframes MCP server（指向 HyperFrames 的 mcp-server.js），之後就能在 Claude 對話中直接下令「生成影片」，Claude 自動呼叫 HyperFrames → HeyGen API 完成生成，無需手動執行 CLI。

HyperFrames 支援繁中旁白嗎？

支援。HyperFrames 的 <script type="speech" lang="zh-TW"> 標籤直接指定繁中語音，由 HeyGen 的 TTS 引擎合成。HeyGen 支援 40+ 語言，繁中語音品質在 2026 年已相當自然。

可以批次生成多支影片嗎？

可以。HyperFrames CLI 支援傳入 JSON 陣列批次生成，也可搭配 n8n 設計自動化流程（讀取資料庫 → 填入 template → 批次生成）。批次生成的速度受 HeyGen API Rate Limit 限制，Creator 方案約 5 支/小時，Team 方案更高。

HyperFrames 生成的影片解析度？

解析度由 HeyGen 方案決定：Free 720p（有浮水印），Creator 1080p，Team 4K。HyperFrames template 可設定輸出格式（16:9 / 9:16 / 1:1），適合不同社群平台。

HyperFrames 跟 Synthesia 比較哪個好？

核心差異在於使用方式：Synthesia 是 GUI 工具，適合非技術用戶；HyperFrames 是程式碼驅動，適合開發者與需要批次生產的場景。如果你需要 Claude Code 自動化生成、或每月超過 50 支影片，HyperFrames + HeyGen 效率遠高於 Synthesia 手動操作。
