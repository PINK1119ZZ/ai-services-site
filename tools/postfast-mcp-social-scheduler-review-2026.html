🔗 PostFast MCP 工作流程：5 步驟讓 Claude 幫你排程社群

PostFast 的核心賣點是 MCP Server 整合。以下是完整設定教學：

  • 步驟 1：註冊 PostFast 帳號 前往 postfast.io，選擇 Starter（€29/月）或 Pro（€79/月）方案，綁定社群帳號。支援 Twitter/X、LinkedIn、Instagram、Facebook、TikTok、Pinterest、YouTube Shorts 等 15+ 平台。
  • 步驟 2：取得 PostFast API Key 登入後前往 Settings → API → Generate Key，複製 API Key 備用。PostFast 提供 REST API 與 MCP Server 兩種接入方式。
  • 步驟 3：設定 Claude MCP Server 在 Claude Desktop 或 Claude Code 的設定中加入 PostFast MCP：
# ~/.claude/settings.json（Claude Code）或 Claude Desktop MCP 設定 { "mcpServers": { "postfast": { "command": "npx", "args": ["-y", "@postfast/mcp-server"], "env": { "POSTFAST_API_KEY": "your_api_key_here" } } } }
  • 步驟 4：用自然語言讓 Claude 幫你排程 設定完成後，直接在 Claude 對話中下指令：「幫我寫一篇關於 AI 工具的 LinkedIn 貼文，明天早上 9 點發布，台灣時間。」Claude 會自動呼叫 PostFast MCP 完成排程。
  • 步驟 5：驗證排程 + 設定自動化工作流 在 PostFast Dashboard 確認貼文已排程。進階用戶可搭配 n8n 設計批次工作流，例如：每週一自動抓取 RSS → Claude 改寫 → PostFast 排程至多平台。

❓ PostFast 常見問題（FAQ）

PostFast MCP 跟 Claude MCP 怎麼連接？

PostFast 提供官方 MCP Server 套件（@postfast/mcp-server），透過 npx 安裝後，在 Claude Desktop 或 Claude Code 的 settings.json 中設定 API Key 即可。設定完成後，Claude 可直接呼叫排程工具，無需打開 PostFast 介面。

PostFast 支援台灣常用的社群平台嗎？

支援 Twitter/X、LinkedIn、Instagram、Facebook、TikTok、Pinterest、YouTube Shorts 等主流平台。台灣特有的 PTT、Dcard、LINE 官方帳號目前不支援，LINE 用戶建議搭配 ManyChat 或 LINE 原生後台。

PostFast 費用用台幣怎麼計算？

PostFast 以歐元計費：Starter €29/月 ≈ NT$975，Pro €79/月 ≈ NT$2,660，Agency €199/月 ≈ NT$6,700。台灣信用卡可直接刷歐元，匯率以發卡行為準。年付通常有 20-25% 折扣。

PostFast 可以跟 n8n 整合嗎？

可以。PostFast 提供完整 REST API（Swagger 文件），n8n 可用 HTTP Request Node 呼叫。常見用法：RSS Feed → n8n → Claude AI 改寫 → PostFast API 排程。Zapier 也有官方整合節點。

PostFast 跟 Buffer 比，哪個比較適合台灣行銷人？

如果你的工作流程以 Claude AI 為中心，且需要 MCP 整合，選 PostFast。如果你主要需要簡單的多平台排程，Buffer 免費版可能就夠用。PostFast 的核心優勢是 AI-native 工作流，Buffer 則是穩定度與使用者數量（全球 70 萬+）。

PostFast 有沒有中文客服？

目前 PostFast 客服以英文為主，支援 Email 和 Discord 社群。介面目前以英文為主，中文支援在 2026 年路線圖中，但尚未正式推出。建議有繁中介面需求的用戶先評估是否能接受英文操作。
